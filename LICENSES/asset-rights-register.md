# 2. 第一性原理

## 2.1 资产权利的唯一问题

```text
对每一个具体资产：

我们是否知道它是什么、
来自哪里、
谁控制哪些权利、
项目将如何使用它、
当前权利是否覆盖该使用、
何时失效、
何处需要署名，
以及若失效后应如何替换？
```

## 2.2 最小可用权利链

一个资产只有在以下链条完整时，才可标记为 `APPROVED_FOR_USE`：

```text
具体资产文件
→ 可定位来源
→ 已知或已审阅权利人
→ 许可/合同/授权/开放许可/公版依据
→ 覆盖项目实际使用方式
→ 覆盖平台、地域、期限和商业模式
→ 满足署名/NOTICE/分发义务
→ 记录进入项目的位置
→ 通过发布前复核
```

以下任一缺失，资产不得被视为可安全进入最终交付：

```text
- 文件无法定位；
- 来源未知；
- 权利人或许可未知；
- 授权只覆盖内部用途；
- 许可已过期；
- 地域、平台或商业用途不覆盖；
- 署名义务未完成；
- AI 输入或输出不可追溯；
- 资产在项目中实际使用位置未知；
- 权利状态与最终交付版本不一致。
```

## 2.3 一项资产可能有多层权利

```text
一个文件不是一个权利。

例如：
一条“人物在咖啡店说话”的视频素材可能同时涉及：

- 视频摄影/剪辑版权；
- 演员表演权；
- 演员肖像、声音与人格权；
- 咖啡店商标、Logo、包装与室内设计；
- 背景音乐词曲、录音与同步权；
- 墙面艺术、海报、字体、屏幕 UI；
- 地点许可；
- 摄制/演出合同；
- 地域、期限、媒介与广告限制。

任一层未清楚处理，
都可能使“看起来已授权的视频文件”不能按计划使用。
```

# 3. 资产状态、风险与可用性

## 3.1 资产权利状态

| 状态 | 定义 | 可否用于开发 | 可否进入生产 | 可否进入最终发布 |
|---|---|---:|---:|---:|
| DISCOVERED | 已发现，未审查 | 是，限内部研究 | 否 | 否 |
| CANDIDATE | 候选资产，等待判断 | 是，限带水印/隔离环境 | 否 | 否 |
| INTERNAL_ONLY | 仅限内部参考或测试 | 是 | 有条件 | 否 |
| RIGHTS_PENDING | 权利/许可/合同待确认 | 有条件 | 否 | 否 |
| LICENSE_REQUESTED | 已申请授权，未获批准 | 有条件 | 否 | 否 |
| LICENSED_LIMITED | 已授权，但用途有限 | 有条件 | 有条件 | 仅在范围内 |
| OPEN_LICENSE_VERIFIED | 开放许可已核验 | 是 | 是 | 有条件 |
| PUBLIC_DOMAIN_CONFIRMED | 公版状态已确认 | 是 | 是 | 有条件 |
| PROJECT_ORIGINAL | 项目原创且权利归属已确认 | 是 | 是 | 有条件 |
| CLIENT_PROVIDED | 客户提供，权利/合同范围已确认 | 是 | 是 | 有条件 |
| TALENT_RELEASED | 含人物/声音，授权已确认 | 是 | 是 | 有条件 |
| APPROVED_FOR_USE | 已覆盖当前具体用途 | 是 | 是 | 是，限已批准范围 |
| RESTRICTED | 仅适用于指定用途、地域、平台、期限或版本 | 有条件 | 有条件 | 有条件 |
| EXPIRING | 即将到期，需续约/替换 | 有条件 | 有条件 | 仅在到期前 |
| EXPIRED | 授权已过期 | 否 | 否 | 否 |
| DISPUTED | 权利或许可存在争议 | 否 | 否 | 否 |
| REPLACEMENT_REQUIRED | 必须替换 | 否 | 否 | 否 |
| REMOVED | 已从项目移除 | 不适用 | 不适用 | 不适用 |
| ARCHIVED | 仅为历史追溯保留 | 否 | 否 | 否 |
| DO_NOT_USE | 明确禁止使用 | 否 | 否 | 否 |

## 3.2 风险等级

| 等级 | 定义 | 最低处理 |
|---|---|---|
| P0 | 未授权/过期/争议资产进入公开、商业、客户或生产交付；或涉及高风险人物、声音、品牌、音乐、隐私、AI 模仿 | 停止使用、替换、取得授权或法务处理 |
| P1 | 权利范围、署名、地域、平台、期限、改编、再分发或合同限制不完整 | 在锁定、生产或发布前解决 |
| P2 | 候选、内部参考、低风险开放材料、待例行复核 | 登记、隔离、按期复核 |
| INFO | 仅需记录来源、归档、版本或信用信息 | 正常维护 |

## 3.3 可用性结论

| 结论 | 含义 | 允许动作 |
|---|---|---|
| USE | 当前用途已获批准 | 可按登记范围使用 |
| USE_WITH_CONDITIONS | 可用，但必须完成具体动作 | 使用前/发布前核验条件 |
| INTERNAL_REFERENCE_ONLY | 仅内部，不得进入对外包 | 可用于灵感/验证，禁止交付 |
| HOLD | 暂停，等待权利或审批结论 | 不进入生产或发布 |
| REPLACE | 必须用其他资产替换 | 创建替换与同步任务 |
| REMOVE | 从项目移除 | 更新剧本、镜头、资产、字幕、片尾 |
| ESCALATE | 必须交由法务/权利负责人/客户决策 | 停止自行判断 |
| ARCHIVE | 不再使用，仅保留追溯记录 | 标记失效并归档 |

## 8.2 替换决策

当资产无法使用或即将失效，按以下顺序选择：

```text
1. 续约或扩大授权；
2. 使用项目原创资产；
3. 使用已确认开放许可或公版资产；
4. 购买或委托制作替代资产；
5. 虚构化品牌、UI、地点、文档或声音；
6. 后期清除、遮挡、替换或重录；
7. 改写镜头、场景、台词或结构；
8. 删除相关叙事功能；
9. 暂停发布或升级法务/客户决策。
```

```text
- 生成脸部近似真实演员；
- 背景含可识别品牌；
- 字体是未授权商业字体；
- 模型条款不覆盖广告投放；
- 海报输出与剧本角色外观不一致。

结论：
ASSET 状态 = HOLD / ESCALATE；
不得进入发布。
```

# 10. 资产审查与发布门禁

## 10.1 单资产审查清单

每个计划进入生产或发布的资产，必须满足：

- [ ] 有唯一 `ASSET ID`
- [ ] 文件、版本、路径/存储 ID 可定位
- [ ] 来源、获取日期、获取人和权利人状态可定位
- [ ] 使用方式和具体出现位置可定位
- [ ] 当前权利状态、许可范围、地域、平台、媒介、期限和商业模式已审查
- [ ] 所有相关权利层已检查或明确不适用
- [ ] 署名、NOTICE、许可证、片尾、UI、元数据或修改说明义务已明确
- [ ] AI 输入/输出记录已完成（如适用）
- [ ] 人物、声音、品牌、地点、地图、字体、音乐、数据与合同限制已审查（如适用）
- [ ] 到期、续约、替换与回滚路径存在
- [ ] 无未关闭 P0
- [ ] 所有关联 Story Bible、剧本、镜头、字幕和音频版本兼容
- [ ] 已获得适用批准

## 10.2 项目级资产锁定门禁

项目资产包可标记 `ASSET_LOCKED` 的最低条件：

- [ ] 当前 Manifest 指向唯一资产包版本
- [ ] 所有进入当前生产/发布包的资产均有 `ASSET ID`
- [ ] 无 `DISCOVERED`、`RIGHTS_PENDING`、`LICENSE_REQUESTED`、`EXPIRED`、`DISPUTED`、`REPLACEMENT_REQUIRED` 或 `DO_NOT_USE` 资产进入锁定包
- [ ] 所有 `LICENSED_LIMITED` 和 `RESTRICTED` 资产的限制已在生产/发布计划中落实
- [ ] 到期资产有提醒、续约或替换方案
- [ ] 片尾、NOTICE、许可证、署名、UI 和元数据已生成并复核
- [ ] AI 输入/输出、模型与平台记录完整
- [ ] 人物、声音、品牌、地点、字体、音乐、UI、地图和数据已完成适用审查
- [ ] 资产与锁定剧本、分镜、镜头、声音和字幕版本一致
- [ ] 权利变更已通过 Notice 同步
- [ ] 无未关闭 P0；P1 仅在有正式风险接受时保留

## 10.3 发布阻断条件

以下任一项存在时，项目不得标记 `RELEASE`：

- [ ] 最终使用的资产没有 `ASSET ID`
- [ ] 资产来源或权利人未知
- [ ] 授权不覆盖商业、广告、客户、平台、地域、媒介、期限或改编用途
- [ ] 授权已过期或临近到期却超出发布期
- [ ] 音乐、录音、声音、人物、肖像、品牌、字体、地图、UI、代码、模型或数据权利链不完整
- [ ] AI 输出无法追溯输入、模型、条款或人工审阅
- [ ] 署名、NOTICE、许可证、片尾或修改说明义务未完成
- [ ] 资产与最终剧本、镜头、字幕、声音或片尾版本不一致
- [ ] 权利变更没有同步到相关场景、镜头、资产或交付物
- [ ] 存在未关闭 P0，或未记录的 P1 例外
- [ ] 客户、法务、平台、表演者、场地、供应商或制作方要求的批准缺失

# 11. 对抗式审查

## 11.1 资产身份检察官

- 这到底是哪一个文件、哪个版本、哪个导出？
- 文件名是否会在复制、上传、外包或剪辑中失去身份？
- 是否存在多个视觉近似但权利不同的版本？
- 是否把“最终.png”“final2.mp4”“新版音频”当作可审计版本？
- 资产能否定位到来源、创建人、时间、哈希或存储 ID？

## 11.2 权利链检察官

- 谁拥有该资产的每一层权利？
- 许可方是否真的有权许可？
- 是否只拿到了转发件、截图、下载链接或口头说法？
- 是否检查了摄影、表演、录音、词曲、肖像、声音、商标、地点、字体、数据和合同等独立层？
- 是否把“购买”“免费”“公开下载”“员工制作”“客户提供”“AI 生成”误认为完整授权？
- 是否能拿出具体证据，而不只是写“已授权”？

## 11.3 使用范围检察官

- 当前实际使用是否超出最初内部、测试、社媒、成片、广告、客户或下载包范围？
- 许可是否覆盖地域、平台、媒介、商业模式、期限、语言、本地化和版本？
- 是否会裁切、重绘、重录、混剪、翻译、变声、训练、微调、嵌入或再分发？
- 是否允许将资产用于预告、海报、广告、品牌合作或付费发行？
- 是否允许跨项目复用？
- 是否存在“成片可用，但营销不可用”的隐藏限制？

## 11.4 叙事与生产检察官

- 此资产服务哪个场景、人物选择、信息揭示或观众承诺？
- 替换它会改变剧情、情绪、节奏、人物识别、证据链或付费点吗？
- 剧本、场景卡、分镜、资产、字幕和声音是否仍指向同一版本？
- 是否存在已生成/已拍资产迫使故事迁就旧事实的情况？
- 竖屏画面中的文字、UI、道具、手部和脸部是否真实可读、可见、可剪？
- 生产限制是否已回写到故事事实和结构，而不是只留在制作备注中？

## 11.5 AI 检察官

- 输入是否有权上传、处理、保留、训练或跨境传输？
- 是否上传了客户机密、未发布剧本、私人图片、声音样本、未成年人或受限数据？
- 输出是否像具体真实人物、演员、配音者、艺术家、品牌、角色或已知作品？
- 平台条款是否覆盖商业、广告、客户交付、地域和再分发？
- 模型、版本、工作流、参考图和提示词是否可追溯？
- 是否把“模型开源”“平台可商用”“AI 自己生成”当作全部权利问题的答案？

## 11.6 到期与发布检察官

- 授权会在项目发布、营销、重播、归档或客户使用期间过期吗？
- 是否已设置足够早的续约提醒？
- 若无法续约，替换需要重拍、重录、重剪、重做字幕、重做片尾还是改写故事？
- 当前最终包是否含过期、争议、旧版、未署名或未清权资产？
- 若明天收到权利异议，团队是否能定位资产、使用位置、授权证据、负责人和替代方案？
- 是否存在因为“已经剪进去了”而放弃权利审查的错误逻辑？

# 13. 最终原则

```text
资产登记册不是“素材清单”。

它是一份项目在任何时刻都能回答的权利与生产控制记录：

这个文件是什么？
它来自哪里？
哪个版本正在被使用？
谁拥有或控制相关权利？
项目究竟怎样使用？
许可是否覆盖地域、平台、期限、商业模式和改编方式？
是否需要署名、NOTICE、片尾或额外批准？
它服务哪个故事与镜头？
若它过期、失效、被拒绝或被异议，
团队能否在不失控的情况下替换、回滚或停止发布？

真正安全的资产不是“已经放进剪辑时间线”。

而是：

身份可定位；
来源可追溯；
权利可证明；
限制可执行；
版本可同步；
失效可替换；
发布可复核。
```
