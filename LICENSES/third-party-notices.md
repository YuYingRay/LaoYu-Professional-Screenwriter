# 1. 第一性原理

## 1.1 必须先回答的五个问题

```text
1. 项目使用了什么第三方材料？

2. 该材料是事实、抽象概念，还是受保护表达/标识/人格内容？

3. 项目如何使用：
   仅内部参考、复制、改编、嵌入、公开展示、
   随包分发、训练、生成、商业发布，还是其他？

4. 谁拥有或控制相关权利？
   该材料适用什么许可、合同、授权、平台条款或法定限制？

5. 项目需要做什么：
   不使用、替换、取得授权、保留署名、附许可证、
   提供通知、开放源码、限制发行，还是提交法务审阅？
```

## 1.2 第三方材料不是单一类别

| 类别 | 例子 | 默认风险 | 关键问题 |
|---|---|---|---|
| 文本与剧本 | 文章、书籍、台词、字幕、新闻、剧本片段 | 高 | 是否复制表达、是否需引用或授权 |
| 图像与视觉 | 照片、海报、截图、画作、地图、UI、电影画面 | 高 | 是否可识别、是否复制构图/资产、是否有素材授权 |
| 音乐与声音 | 歌曲、录音、音效、配音、采样、音色 | 高 | 词曲、录音、表演、同步、平台权利是否分离 |
| 字体与图形 | 字体、Logo、图标、图形模板、动态组件 | 中至高 | 许可证是否允许嵌入、商业使用、再分发 |
| 软件与代码 | 字体工具、插件、库、脚本、模型、依赖 | 中至高 | 许可、NOTICE、源码提供、分发义务 |
| 品牌与标识 | 商标、产品外观、平台界面、机构标志 | 中至高 | 是否暗示关联、混淆、贬损或商业使用风险 |
| 人格与身份 | 姓名、肖像、声音、社交内容、表演、数字替身 | 高 | 肖像、隐私、人格、合同、AI 模仿风险 |
| 地点与建筑 | 私有场地、独特建筑、室内设计、公共艺术 | 中 | 拍摄/展示许可、标识、艺术品与物业限制 |
| 数据与数据库 | 数据集、榜单、地图数据、字幕数据、元数据 | 中至高 | 数据库权、隐私、合同、再分发与模型使用 |
| AI 输入/输出 | 参考图、提示词、训练集、生成角色/声音 | 高 | 输入权利、平台条款、输出可用性、相似性与肖像风险 |

## 1.3 权利层拆分

```text
同一个“素材”可能同时包含多个独立权利层。

例如一张电影海报可能涉及：
- 摄影或插画版权；
- 平面设计版权；
- 演员肖像与合同权利；
- 电影片名与商标；
- 角色形象；
- 字体许可；
- 发行方的商业标识。

取得其中一层许可，
不等于取得全部层的使用权。
```

# 2. 使用状态与风险等级

## 2.1 使用状态

| 状态 | 含义 | 可否纳入最终交付 |
|---|---|---|
| NOT_REVIEWED | 已发现，尚未判断 | 否 |
| RESEARCH_ONLY | 仅作事实/灵感研究，不复制表达 | 通常不纳入素材包 |
| INTERNAL_REFERENCE | 内部参考，不公开、不分发 | 有条件；需确认合同/保密限制 |
| REQUESTED | 已申请授权，未获答复 | 否 |
| LICENSED | 已获得足以覆盖当前用途的许可 | 有条件；须遵守范围与署名 |
| PUBLIC_DOMAIN_CONFIRMED | 已确认处于适用公版范围 | 有条件；仍核验版本、地区与人格/商标等 |
| OPEN_LICENSE_VERIFIED | 已确认开放许可与本项目用途兼容 | 有条件；须满足署名/传递条款 |
| FAIR_USE_OR_EQUIVALENT_PENDING | 拟主张合理使用/法定例外，尚未专业确认 | 否 |
| FAIR_USE_OR_EQUIVALENT_APPROVED | 已获得适用专业意见 | 有条件；严格限于意见范围 |
| REPLACED | 已用原创/授权材料替换 | 是 |
| REMOVED | 已从项目移除 | 不适用 |
| RESTRICTED | 存在限制，仅限特定用途或地域 | 仅限授权范围 |
| EXPIRED | 原许可或授权已过期 | 否 |
| DISPUTED | 权利归属或使用许可存在争议 | 否 |
| DO_NOT_USE | 禁止使用 | 否 |

## 2.2 风险等级

| 等级 | 定义 | 最低处理 |
|---|---|---|
| P0 | 未授权且已进入公开/商业交付；真实人物、音乐、电影画面、品牌、AI 模仿或敏感数据等高风险对象 | 停止使用，替换或法务处理 |
| P1 | 权利链不完整、许可范围不明、署名/分发义务未完成、可能影响制作或发布 | 在锁定/发布前解决 |
| P2 | 内部参考、低风险开放材料、尚未进入交付物的线索 | 登记、复核、避免误用 |
| INFO | 无实质权利风险，但需保留信用或来源记录 | 正常归档 |

## 2.3 权利审查红线

以下任一情况默认触发 `P0` 或 `P1`，并应进行专业审阅：

- [ ] 使用受版权保护电影、剧集、书籍、剧本、歌词、文章、图片或视频的实质表达
- [ ] 使用音乐、录音、音效采样、配音、声音克隆或可识别音色
- [ ] 使用真实人物、演员、网红、客户、未成年人或可识别私人的肖像、声音、姓名或私密资料
- [ ] 使用真实商标、Logo、平台界面、产品包装、品牌名称或虚构品牌可能造成混淆
- [ ] 使用第三方字体、地图、图标、模板、模型、插件、代码或数据集
- [ ] 使用社交媒体内容、评论、私信、截图、用户生成内容或新闻图片
- [ ] 使用 AI 参考图、风格提示、角色锚点、数字替身或训练材料
- [ ] 使用敏感地点、公共艺术、私有建筑、博物馆、演出、体育赛事或受限场所
- [ ] 将开放许可材料再分发、嵌入交付物或用于商业发布
- [ ] 项目涉及跨地域发行、付费、广告、赞助、品牌合作或客户交付
- [ ] 项目存在保密、雇佣、客户、工会、表演者、平台或供应商合同义务

## 登记原则

```text
一项材料 = 一条登记。

若一个来源含有多个不同素材、不同许可、不同权利人、
不同使用方式或不同分发范围，应拆分为多条。

例如：
- 同一首歌的词曲权与录音权，应分别登记；
- 同一张照片中的摄影、人物肖像、商标和建筑艺术，
  必要时应分别登记；
- 同一个 AI 输出若使用不同参考图、不同角色声音或不同平台，
  应分别追踪；
- 同一字体在内部设计、嵌入视频、分发项目文件时，
  可能需要不同许可判断。
```

# 5. 使用方式决策树

```text
问题 1：
项目是否复制、展示、嵌入、分发、改编或以可识别表达方式使用第三方材料？

否：
→ 通常不进入本文件；
→ 若用于事实核验，进入 source-links.md；
→ 若仅作灵感，记录内部创作说明，避免复制具体表达。

是：
→ 进入问题 2。
```

```text
问题 2：
材料是否已明确处于可用状态，
且其许可/授权覆盖当前使用方式、地域、期限、媒介与商业用途？

是：
→ 登记许可证、署名、通知、范围与到期日；
→ 执行必要信用与分发义务；
→ 进入 asset-rights-register.md。

否或不确定：
→ 进入问题 3。
```

```text
问题 3：
能否以原创、授权替代品、已确认开放许可或已确认公版材料实现同样叙事功能？

能：
→ 优先替换；
→ 原材料状态设为 REPLACED / REMOVED。

不能：
→ 暂停纳入最终交付；
→ 申请授权或提交法务审阅；
→ 建立风险与阻断项；
→ 不得以“网上有”“别人也在用”“只用几秒”代替确认。
```

# 6. 常见材料专项规则

> 以下为风险提示与工作流，不是法律结论。

## 6.1 剧本、台词、书籍、文章与歌词

| 风险点 | 审查问题 | 推荐动作 |
|---|---|---|
| 逐字复制 | 是否复制可识别、实质性文字表达？ | 删除、原创重写、取得授权或寻求专业意见 |
| 翻译 | 是否把受保护文本换语言后使用？ | 翻译通常仍可能涉及改编权；不得假定可用 |
| 角色与情节 | 是否复制独特角色、场景编排、对白、世界设定或情节表达？ | 只提取抽象类型机制；重建原创人物、因果与表达 |
| 歌词 | 是否使用歌词、标题、可识别段落或字幕？ | 默认高风险，避免使用或处理权利 |
| 新闻/采访 | 是否复制采访措辞、照片、视频或独家材料？ | 将事实与表达分离；事实进来源日志，素材另行授权 |

红旗：

- [ ] “我只改了几个字”
- [ ] “我翻译成中文了”
- [ ] “只是致敬”
- [ ] “只用一句经典台词”
- [ ] “网上到处都有”
- [ ] “只是内部 Pitch”
- [ ] “AI 生成的，所以没有问题”

## 6.2 图像、视频、电影画面与截图

# 7. 开放许可、公版与例外处理

## 7.1 开放许可不等于无条件使用

即使材料标有“免费”“开源”“Creative Commons”“Public Domain”
或“免版税”，仍须确认：

```text
- 许可证名称和版本；
- 发布者是否有权授予许可；
- 材料是否真是该许可覆盖的版本；
- 当前项目是否属于许可允许的用途；
- 是否可商业使用；
- 是否可修改；
- 是否可再分发；
- 是否需署名、链接、许可文本、修改说明或同许可；
- 是否有地域、平台、媒体、期限、数据、肖像、商标或合同限制；
- 是否存在独立的第三方权利层。
```

## 7.2 Creative Commons 处理表

| 许可 | 商业使用 | 改编 | 常见项目处理 |
|---|---|---|---|
| CC0 | 通常允许 | 通常允许 | 仍核验发布者权利、人格/商标/隐私与地区问题 |
| CC BY | 通常允许 | 通常允许 | 保留署名、链接、修改说明 |
| CC BY-SA | 通常允许 | 通常允许，但有同许可要求 | 发行与衍生分发前需审查兼容性 |
| CC BY-ND | 通常允许 | 不允许改编 | 裁切、翻译、配乐、重绘、合成等可能需审查 |
| CC BY-NC | 不允许商业用途 | 有条件 | 商业、广告、付费、品牌项目通常不适用 |
| CC BY-NC-SA | 不允许商业用途 | 有同许可要求 | 通常不适合商业项目 |
| CC BY-NC-ND | 不允许商业与改编 | 限制严格 | 通常不适合制作使用 |

> 此表仅为操作性提示。
> 实际判断以适用许可文本、材料来源、项目使用方式及专业意见为准。


# 11. 对抗式审查

## 11.1 权利链检察官

- 这项材料到底由谁创作、谁拥有、谁有权许可？
- 获取文件的人是否真的有授权能力？
- 我们拿到的是原件、转载、截图、压缩版、二次编辑版还是未知版本？
- 许可证是否明确覆盖当前版本，而非一个不同版本？
- 是否存在摄影、表演、录音、字体、肖像、商标、地点、数据等独立权利层？
- 是否把“付费购买”“免费获取”“公开下载”“他人转发”误认为完整授权？

## 11.2 使用方式检察官

- 项目是内部参考、公开展示、商业发行、广告、客户交付还是可下载再分发？
- 是否会裁切、翻译、重绘、配乐、变声、训练、微调、合成或生成衍生内容？
- 当前许可是否允许这些具体行为？
- 是否会跨地区、跨平台、跨媒介、跨期限或跨受众使用？
- 是否从“内部测试”悄悄升级为“公开营销”？
- 是否允许用户提取、下载或再利用该材料？

## 11.3 署名与通知检察官

- 是否保留原始版权、署名、许可与 NOTICE？
- 是否需要完整许可文本，而非只写一个链接？
- 署名是否放在正确位置、以可读方式呈现？
- 是否需说明修改、翻译或衍生关系？
- 是否有代码、字体、模型、数据或素材被分发却未列入发布包？
- 是否把本项目的原创声明错误覆盖在第三方材料之上？

## 11.4 创作边界检察官

- 我们是在使用抽象事实/概念，还是复制独特表达？
- 是否可通过原创重做实现相同戏剧功能？
- 是否存在对某部作品、角色、海报、界面、音乐、声音或导演风格的过度接近？
- 是否把“致敬”“戏仿”“灵感”“AI 生成”当成不处理权利的理由？
- 真实品牌、人物或机构是否可被观众识别，即使名称已被改动？
- 是否有不必要的第三方元素可以删去而不伤害故事？

## 11.5 AI 检察官

- 输入材料是否有上传、处理、训练、保留或再利用限制？
- 生成结果是否近似特定真实人物、在世创作者、角色、商标或已知作品？
- AI 声音是否实际模仿特定个体？
- 该平台是否给予商业使用、客户交付、再分发和地域发行所需权利？
- 是否已保存足够记录，以追溯某个输出用过什么输入与模型？
- 输出是否需要人工审阅、替换、重新生成或法务处理？

## 11.6 发布检察官

- 所有 P0 是否已关闭？
- P1 是否已关闭，或具有正式书面接受与补偿措施？
- 最终片尾、字幕、About、README、下载包和应用内通知是否一致？
- 发行地域、平台、商业模式和期限是否都在授权范围内？
- 是否有旧资产、旧音频、旧图片或旧 UI 在最终剪辑中被遗漏？
- 若明天收到权利异议，团队能否定位材料、使用位置、授权证据、负责人和替换方案？

# 13. 最终原则

```text
第三方通知不是片尾最后一页的形式工作。

它是一套可追溯的判断系统：

项目到底使用了什么；
使用的是事实、概念，还是受保护表达；
谁拥有哪一层权利；
当前许可覆盖哪些用途；
需要怎样署名、通知、分发或限制；
何时必须替换、暂停、授权或寻求专业审阅。

最安全的默认规则不是：
“没有人会发现。”

而是：

没有清楚的权利链，
就不进入最终交付。
```
