# 对白重写样例：别替我签字

> 原创示例。
>
> 用途：
>
> - 演示对白从“解释信息”重写为“角色用语言行动”；
> - 演示目标、阻碍、潜台词、权力和转折如何先于台词存在；
> - 演示如何区分“必要直说”与“无效直白”；
> - 演示重写后如何进行对抗式审查。
>
> 本文件不是台词辞典。
>
> 核心原则：
>
> ```text
> 如果人物没有目标，对白不会有行动；
> 如果双方目标不冲突，对白不会有张力；
> 如果状态不改变，再漂亮的对白也只是停留。
> ```

---

# 1. 使用情境

本样例取自原创长片开发项目《潮线之下》。

## 已锁定故事事实

| 项目 | 当前事实 |
|---|---|
| 主角 | 顾岚，前港口安全工程师 |
| 弟弟 | 顾川，仍在旧城区工作 |
| 旧秘密 | 顾岚三年前签过一份报告，导致旧城区撤离被延迟；哥哥在那次事故中死亡 |
| 当前危机 | 风暴将至，旧城区再次被列为低优先级，唯一防潮隧道被关闭 |
| 本场位置 | 长片约第 56 分钟；中点后、第二幕中段 |
| 前场后果 | 顾岚拿到原始报告的一部分；顾川发现她知道旧事故更多细节 |
| 顾岚当前策略 | 仍试图“先救人，之后再解释” |
| 顾川当前策略 | 拒绝再被姐姐保护式隐瞒，要求参与决定 |
| 本场结束状态 | 顾川拿走隧道图，决定自己去现场；顾岚失去对他的控制 |

## 本场一句话

```text
当顾岚试图阻止顾川进入即将进水的防潮隧道时，
顾川发现她又准备替他签下风险决定；
他夺走隧道图，逼顾岚面对：
她所谓的保护，仍然是把选择权从他手里拿走。
```

---

# 2. 第一性原理诊断

## 2.1 这场真正的冲突

| 元素 | 顾岚 | 顾川 |
|---|---|---|
| 表面目标 | 让顾川离开旧城区，不进隧道 | 拿到隧道图，进入现场救被困居民 |
| 深层目标 | 继续保住“姐姐能控制风险”的身份 | 证明自己不是姐姐必须管理的对象 |
| 恐惧 | 顾川知道哥哥死亡与她有关 | 再次在不知情时承担姐姐替他决定的后果 |
| 可用资源 | 技术知识、隧道图、年龄/经验权威 | 对现场和居民的熟悉、道德压力、对姐姐模式的了解 |
| 不能直接说 | “我怕你知道我害过哥哥。” | “我宁愿冒险也不愿再相信你。” |
| 本场底线 | 不让顾川看完整报告 | 不接受顾岚代替自己决定 |
| 本场后变化 | 失去隧道图与控制 | 得到行动权，但进入更大危险 |

## 2.2 开场与结尾状态

```text
开场：
顾岚拥有隧道图、信息和行动主动权；
顾川知道姐姐隐瞒，但还没有证据证明她又在替自己决定。

结尾：
顾川拿到隧道图并离开；
顾岚第一次无法再把“我来处理”伪装成关心。
```

## 2.3 为什么必须有这场

- 顾川后续进入隧道，必须是被人物关系和已知风险驱动，而非“他突然冲动”。
- 顾岚的旧策略必须在中点后明确失败；否则高潮把确认权交给顾川没有足够的情感因果。
- 本场让“保护”从抽象主题变成一个具体动作：**替对方签字/决定风险**。
- 本场从“姐姐对弟弟隐瞒”升级为“弟弟拒绝被管理”。

## 2.4 删除测试

```text
若删去本场：

顾川之后拿走隧道图并进入隧道，
会显得像为了制造动作而行动；

顾岚在高潮交出确认权，
会显得像突然学会主题；

姐妹/姐弟关系的权力转移缺少可见节点。

结论：
本场不可删除，但必须避免变成信息说明会。
```

# 3. 失败版本

> 以下版本故意写得不成立。
>
> 它的问题不在于“太直白”本身，而在于角色没有用话语争取目标；
> 台词只是在把作者已知信息交给观众。

```text
内景 旧城区临时诊所 - 夜

雨打在窗上。

顾川拿着一张隧道图。

顾岚走进来。

顾岚
你不能去防潮隧道，因为那里很危险。

顾川
我必须去，因为居民都被困在那里。

顾岚
我不想让你去，因为三年前哥哥就是在隧道里死的，
而且我签过那份导致撤离延迟的报告。

顾川
所以你一直对我隐瞒真相。

顾岚
是的，因为我想保护你。

顾川
但你不能总是保护我，
我已经是成年人了。

顾岚
我知道，但是你不知道隧道的危险。

顾川
我知道它很危险，
但我还是要去。

顾岚
那我也没办法。

顾川离开。
```

# 4. 失败版本审查

## 4.1 表层问题

| 位置 | 问题 | 为什么无效 |
|---|---|---|
| “那里很危险” | 泛泛警告 | 没有具体风险、没有策略、没有交换 |
| “我签过那份报告” | 过早且无压力地完整坦白 | 真相没有被争取、逼出或付代价 |
| “我已经是成年人了” | 抽象主题口号 | 没有把“选择权”落到可行动的对象上 |
| “那我也没办法” | 主角放弃行动 | 场景没有通过对抗走到结果，只是作者让角色离开 |
| 顾川离开 | 无可见夺取或选择 | 结尾状态变化弱，下一场缺乏因果推动 |

## 4.2 第一性原理问题

| 维度 | 失败版本 | 后果 |
|---|---|---|
| 目标 | 双方只在“表达观点” | 没有人真正争取资源 |
| 阻碍 | “危险”是口头标签 | 没有具体行动压力 |
| 策略 | 顾岚只重复劝阻；顾川只重复坚持 | 对话没有升级 |
| 潜台词 | 所有人说出全部真实想法 | 无法让观众参与解读 |
| 权力 | 从头到尾没有变化 | 场景停滞 |
| 转折 | 没有触发动作 | 顾川离开像作者安排 |
| 后果 | 没有新的资源、信息或关系状态 | 下一场可随意发生 |

## 4.3 为什么不能只“把台词写含蓄一点”

错误修复：

```text
顾岚
你确定要去？

顾川
你确定要拦我？

顾岚
我是在帮你。

顾川
你一直都这么说。
```

这比失败版本少说了一点，但仍然失败：

- 目标依然模糊；
- 没有可争夺的具体资源；
- 没有逼迫人物改变策略；
- 没有真正的转折；
- 结尾仍可被任意替换。

> 潜台词不是“把真话说得更神秘”。
>
> 潜台词是人物因为害怕失去资源、关系、身份或控制权，而不能直接说出的行动目的。

# 5. 重写前的场景设计

## 5.1 争夺对象

```text
具体对象：折叠的防潮隧道图。

它不是装饰性道具。
它代表：

顾岚拥有的信息优势；
顾川能否进入现场；
谁有权决定风险；
顾岚是否还在替顾川签下人生决定。
```

## 5.2 对白行动动词

| 角色 | 说话不是为了“表达感受”，而是为了… |
|---|---|
| 顾岚 | 收回、拖延、缩小风险、保护秘密、重新夺回地图 |
| 顾川 | 试探、逼问、拒绝、夺取、迫使姐姐承认控制欲 |

## 5.3 策略阶梯

| 阶段 | 顾岚 | 顾川 | 权力 |
|---|---|---|---|
| 开场 | 用技术细节把顾川排除在行动外 | 假装只是来取工具 | 顾岚占优：有图、有信息 |
| 施压 | 以“安全”名义命令他离开 | 指出她又替他做决定 | 顾岚仍占优，但被击中模式 |
| 升级 | 用哥哥的旧物转移话题，试图唤起顾川恐惧 | 拿出未签署的撤离表 | 顾川取得道德与事实优势 |
| 转折 | 顾岚要替顾川签字 | 顾川抢走地图，拒绝她的签名 | 权力反转 |
| 退出 | 顾岚失去地图与控制 | 顾川得到行动权，也承担风险 | 新状态不可回退 |

## 5.4 信息分配

| 信息 | 顾岚 | 顾川 | 观众 | 本场变化 |
|---|---|---|---|---|
| 隧道将在 18 分钟后锁死 | 知道 | 部分知道 | 知道 | 顾川得到更具体时间压力 |
| 顾岚签过旧报告 | 知道 | 怀疑 | 知道 | 顾川从怀疑转为确认 |
| 报告关联哥哥死亡 | 知道 | 不知道完整版本 | 知道 | 本场只暗示，不完整揭示 |
| 顾川已经决定进隧道 | 不知道 | 知道 | 知道 | 结尾兑现 |
| 撤离表需要本人确认 | 知道 | 不知道 | 知道 | 顾岚试图替签，暴露核心问题 |

> 注意：
>
> 顾岚不在本场完整坦白旧事故。
> 不是为了拖延剧情，而是因为她仍在执行旧策略。
>
> 她会在后续危机中被逼到无法再只交出一半真相。
> 若后续不兑现，这种保留就会变成廉价拖延。

# 7. 重写版本逐拍拆解

## 7.1 开场：用动作建立不平等

```text
顾岚把隧道图折小，塞进内袋。
顾川翻找手电。
```

作用：

- 顾岚先占有核心资源；
- 顾川并非坐等信息，而是在为进入隧道准备；
- 道具建立后续可争夺对象；
- 两人的行动目标在台词前已经冲突。

## 7.2 第一轮：技术语言作为控制

```text
顾岚：
“拿黄灯那支。白灯进水就报废。”
```

表面：

```text
给出实用建议。
```

真实行动：

```text
顾岚用专业细节确认自己拥有解释权；
她把顾川放在“需要被指导的人”位置。
```

顾川的反击：

```text
“你什么时候开始管灯了？”
```

他没有说“你很控制我”。

他攻击的是顾岚突然出现的控制欲，并迫使她承认自己知道顾川要去哪里。

## 7.3 第二轮：把抽象危险变成倒计时

```text
顾川：
“十八分钟。”
```

作用：

- 具体化风险；
- 证明顾川并非完全无知；
- 让顾岚不能继续用“等一等”拖延；
- 把场景从争论升级为时间压力下的资源争夺。

## 7.4 第三轮：撤离表让主题变成动作

```text
顾川：
“那张表谁签？”
```

这不是“你是不是控制我”的解释性问句。

这是一个可验证问题：

- 谁签，谁决定；
- 谁签，谁承担法律/道德责任；
- 顾岚若代签，就把“保护”变成具体的剥夺。

## 7.5 转折前：旧秘密作为武器，而非说明

```text
顾川：
“哥哥那次，你也这么说？”
```

这句没有完整解释事故。

它只完成：

- 把顾岚从当前技术权威拉回过去责任；
- 让她失去“现在不是算旧账”的话语优势；
- 提示观众此处有更大的未解真相；
- 逼顾岚暴露防御性，而不是获得一次方便的坦白机会。

## 7.6 转折：资源易主

```text
顾川拿走地图。
```

这是实际行动，不是情绪结论。

因此：

```text
开场：
顾岚有图、有专业信息、有签字权。

结尾：
顾川有图、有现场行动权；
顾岚只剩一支她无法替他使用的黄灯。
```

## 7.7 结尾：沉默比解释更有用

```text
顾川：
“那你告诉我。”

顾岚没说。
```

这个沉默成立的前提是：

- 已建立顾岚知道哪段会灌水；
- 已建立她有理由害怕顾川进入；
- 已建立她的沉默不是因为作者不愿提供信息，而是因为说出信息会承认她一直在替顾川决定。

若没有这些前提，沉默会变成故弄玄虚。

# 8. 重写前后对比

| 维度 | 失败版本 | 重写版本 |
|---|---|---|
| 场景目标 | 模糊地争论“去不去” | 争夺隧道图与现场确认权 |
| 阻碍 | “那里危险” | 倒计时、撤离表、未说出的事故真相、地图 |
| 顾岚策略 | 重复劝阻 | 用专业细节、签字权、隐瞒和身体位置控制局面 |
| 顾川策略 | 重复坚持 | 试探信息、指出模式、阻止代签、夺取地图 |
| 信息 | 全部直接说出 | 每句只释放当前冲突所需信息 |
| 潜台词 | 无 | “安全建议”实际是控制；“别签”实际是夺回选择权 |

| 下场驱动 | 无明确因果 | 顾岚必须追入风险区；高潮必须处理“谁确认开门” |

# 9. 哪些直白台词应当保留

> “避免直白”不等于让角色永远绕圈。
>
> 在高压、决断、揭露和后果时，直接语言往往更有力量。
> 判断标准不是“这句话是否说得明白”，而是：
>
> ```text
> 这句话是否是人物为了改变局面而必须说出的行动？
> ```

## 应保留的直白

```text
顾川
别签。
```

原因：

- 这是明确的即时行动；
- 它指向可见道具与具体风险；
- 它改变顾岚下一步动作；
- 若改成隐晦表达，反而会削弱现场紧迫性。

```text
顾岚
那不是给你的。
```

原因：

- 不是解释世界观；
- 是她试图重新夺回地图的控制声明；
- 让顾川能精准反击：“所以我才要拿。”

## 应删除或改写的直白

```text
顾岚
我不能告诉你，因为我害怕你知道我参与了哥哥死亡。
```

问题：

- 顾岚在此刻仍未准备好坦白；
- 她说出完整心理诊断会跳过后续危机；
- 观众从她停笔、避答、转移话题和地图控制中已能读到足够信息。

可替代为：

```text
顾川
那你告诉我。

顾岚没说。
```

> 这不是少给信息，而是让角色的拒绝本身成为信息。

# 10. 声音区分审查

## 顾岚

| 特征 | 示例 |
|---|---|
| 先给方案，后承认感受 | “拿黄灯那支。” |
| 用技术细节绕开情感 | “白灯进水就报废。” |
| 被逼急后句子更短 | “别拿他逼我。” |
| 控制欲通过动词出现 | 拿走、翻过去、塞进、追上 |

## 顾川

| 特征 | 示例 |
|---|---|
| 先用具体事实刺破顾岚 | “十八分钟。” |
| 不直接说“你控制我”，而是指出她的重复动作 | “你又准备替别人填空。” |
| 在真正受伤时反而更简洁 | “别签。” |
| 反击方式是夺取行动权 | 拿地图、离开、进入现场 |

## 声音替换测试

```text
把角色名遮掉：

“拿黄灯那支。白灯进水就报废。”
更像顾岚，因为它将情感转译为技术控制。

“你又准备替别人填空。”
更像顾川，因为他攻击的是顾岚的重复模式，而非单一事件。

如果任意一人说任意一句都成立，
则声音仍需重写。
```

# 11. 对抗式审查

> 以下是按 `references/adversarial-review-rubric.md#3-评审角色`完成的实例结果；
> 填写职责见 `references/adversarial-review-rubric.md#9-审查报告模板`。这些结论是本示例证据，不是新的角色问题清单。

## 11.1 怀疑观众审查结果

| 问题 | 结论 | 是否修复 |
|---|---|---|
| 我是否在 10 秒内知道两人争什么？ | 是，顾岚藏图，顾川找灯并要进隧道 | 是 |
| 我是否理解为什么不能简单“谈一谈”？ | 是，18 分钟倒计时与水压窗口存在 | 是 |
| 我是否感到两人重复同一争论？ | 否，策略从指导、拖延、代签、逼问到夺图 | 是 |
| 结尾是否改变状态？ | 是，地图和行动权易主 | 是 |
| 我是否能理解下一场为何发生？ | 是，顾岚必须追顾川，或改用新策略 | 是 |

## 11.2 逻辑检察官审查结果

| 质疑 | 答案 | 待补强 |
|---|---|---|
| 顾川如何知道“18 分钟”？ | 前场他从系统广播和顾岚电话中拼出时间 | 前场应有明确视觉/听觉线索 |
| 顾岚为什么不直接抢回地图？ | 她可物理靠近，但顾川在门边；强抢会耽误时间并加剧关系，且她旧伤不利 | 动作设计中强调她手部旧伤 |
| 顾川拿图后真的能看懂吗？ | 他熟悉旧城区通道，但不懂全部结构 | 后续场显示他会误判一段路线，迫使他需要顾岚信息 |
| 为什么顾岚不马上告诉他灌水段？ | 她说出具体风险就要承认她早知且一直隐瞒；这是她当下未完成的变化 | 后续危机必须兑现，不能无限拖延 |

## 11.3 人物辩护人审查结果

| 角色 | 潜在不可信之处 | 当前支撑 | 必要补强 |
|---|---|---|---|
| 顾岚 | 她为何仍不坦白？ | 多年以隐瞒等同保护；公开签名会失去弟弟 | 前段展示她曾替顾川处理债务且不告知 |
| 顾川 | 为何冒险进入隧道？ | 居民被困，他熟悉现场，且不信官方与姐姐 | 前段展示他与居民的现实联系 |
| 两人 | 为什么现在爆发？ | 倒计时、撤离表、哥哥旧案被重新触发 | 前场必须让顾川看到报告边角或听到关键词 |

## 11.4 节奏横切检查结果

| 检查项 | 结论 |
|---|---|
| 能否更晚进入？ | 已从“顾川准备手电、顾岚藏图”进入，无需寒暄。 |
| 能否更早离开？ | 顾川夺图、顾岚无法回答后立即离开；应切出。 |
| 是否重复信息？ | “18 分钟”“别签”“地图”各承担不同升级功能。 |
| 是否需要完整坦白？ | 不需要；完整坦白应留给后续危机，否则会提前耗尽主角弧。 |

## 11.5 制作与风险制片人审查结果

| 项目 | 风险 | 最小可行方案 |
|---|---|---|
| 雨夜窗外 | 天气/反光成本 | 窗面水痕、环境声、局部灯光和后期雨线 |
| 纸质地图 | 小字不可读 | 地图只需可见折痕、颜色分区和人物争夺；具体路线后期局部合成 |
| 手部夺图 | AI 手部一致性 | 拆为：衣袋特写 → 顾川抽出纸张 → 顾岚反应 → 地图在顾川手中 |
| 长对白口型 | AI 口型风险 | 正反打、背影、手部、环境声与后期配音 |
| 9:16 构图 | 两人争夺需保持面部可读 | 多用前后景双人构图、门框纵深、CU/MCU，避免横向走位 |

# 12. 重写流程模板

> 对任何一场对白，按以下顺序工作。
>
> 不要先替换词语、添加隐喻或制造“金句”。

## 第一步：先写无对白版本

```text
人物 A 想从人物 B 手中/身上得到什么？
人物 B 如何拒绝？
可争夺对象是什么？
谁先拥有权力？
谁在结尾拥有权力？
```

若无对白版本无法成立，先修场景卡，不修台词。

## 第二步：给每句台词一个动词

| 台词 | 说话者真正动作 |
|---|---|
| “拿黄灯那支。” | 指挥 |
| “十八分钟。” | 逼迫面对现实 |
| “别签。” | 阻止/夺权 |
| “那不是给你的。” | 收回控制 |
| “那你告诉我。” | 设下无法回避的测试 |

若某句只能标为“解释”“评论”“表达情绪”，优先删除、转为动作，或让它承担更明确的行动。

## 第三步：检查信息是否可由行为承载

将：

```text
“我害怕你知道真相。”
```

替换为：

```text
人物停笔、翻纸、避答、收起证据、改变话题、离开。
```

但注意：

```text
行为不能替代观众必须理解的事实。
关键规则、明确决定、危机条件与高潮选择，
在需要时必须说清楚。
```

## 第四步：让对话改变状态

```text
开场：
谁拥有信息、资源、空间、合法性或情感主动权？

结尾：
谁失去什么？
谁得到什么？
谁被迫进入下一步？
```

若答案仍是“他们更生气了”，场景通常不够。

## 第五步：对抗复审

- [ ] 角色是否用语言争取具体目标？
- [ ] 对手是否有不同且冲突的目标？
- [ ] 是否存在可见对象、信息或权力可被争夺？
- [ ] 是否至少有一次策略变化？
- [ ] 是否把作者解释伪装成人物谈话？
- [ ] 潜台词是否来自真实的不能说，而不是故意卖关子？
- [ ] 关键直白是否保留在需要行动、决定或后果的地方？
- [ ] 结尾状态是否与开场不同？
- [ ] 下一场是否由本场结果必然引出？

# 13. 常见误修

| 误修 | 看似改善 | 实际问题 | 正确方向 |
|---|---|---|---|
| 全部改成谜语 | “更有潜台词” | 观众无法理解人物在争什么 | 保留目标和风险，只隐藏人物不敢承认的部分 |
| 增加金句 | “更有文学性” | 台词停下动作，角色像作者 | 让语言完成威胁、交换、试探或夺权 |
| 每个人都沉默 | “更电影化” | 关键规则与决定不清楚 | 用沉默承载回避，用直说承载行动 |
| 加更多背景说明 | “观众终于懂了” | 节奏停滞，角色沦为讲解员 | 将信息拆入选择、道具、失败和后果 |
| 让角色吵得更大声 | “冲突更强” | 没有策略、资源或权力变化 | 改变对方可得资源、风险和选择空间 |
| 提前完整坦白 | “情感更真诚” | 主角弧失去后续压力 | 只在角色被逼到必须说时，让坦白造成真实代价 |
| 用误会延长 | “能多写几场” | 角色显得失智，观众失去信任 | 让隐瞒每次产生具体代价，并设置兑现节点 |

# 14. 最终原则

```text
对白不是人物把内心字幕念出来。

对白是人物在不能轻易说真话时，
仍试图从对方那里得到某种东西：

许可、
信任、
服从、
原谅、
资源、
沉默、
承认，
或选择权。

当语言改变了谁能做什么，
它才是场景行动。

当沉默、停顿、动作和回避
都来自人物真正害怕失去的东西，
潜台词才不是装饰，
而是冲突本身。
```
