# 长片大纲样例：潮线之下

> 原创开发样例。
>
> 用途：
>
> - 演示 `feature-screenplay.fountain`、`episode-outline.md`、`scene-card.md` 的实际使用；
> - 演示从第一性原理建立长片：目标、阻碍、选择、后果；
> - 演示如何用八序列检查结构功能，而不把结构误解为死板时间公式；
> - 演示对抗式审查如何提前发现因果、人物、信息与制作问题。
>
> 本样例为虚构故事；港口、公司、救援系统、人物、规则与地点均为原创。
> 不把现实海事、应急、法律或工程流程当作已核验事实。
> 进入制作前，应由相关专业顾问验证所有现实细节。

---

# 1. 项目快照

| 项目 | 内容 |
|---|---|
| 项目名 | 《潮线之下》 |
| 英文工作名 | *Below the Tide Line* |
| 类型 | 灾难悬疑 / 家庭剧情 / 港口惊悚 |
| 格式 | 长片 |
| 目标时长 | 100–110 分钟 |
| 画幅 | 2.39:1 或 16:9 |
| 核心受众 | 喜欢高压道德选择、有限空间惊悚、家庭关系与现实感灾难片的观众 |
| 主要地点 | 海港调度中心、旧防潮隧道、维修船、码头诊所、海堤 |
| 主角 | 顾岚，前港口安全工程师 |
| 对手 | 程野，港口运营公司总调度；以及正在上涨的潮水与失效系统 |
| 核心关系 | 顾岚与弟弟顾川；顾岚与程野 |
| 主题 | 责任不是替别人承担风险，而是在真相出现时把选择权还给他们 |
| 内容边界 | 不展示现实可操作的关键基础设施破坏方式；危险操作保持戏剧化和非操作性；未成年人不处于可模仿危险行为中。 |

## Logline

```text
当一场异常风暴即将淹没海港旧城区时，
因一次救援事故被停职的安全工程师顾岚发现港口公司故意关闭了唯一的防潮隧道；
她必须在潮水抵达前重启隧道并疏散被困居民，
但这意味着公开自己当年伪造安全报告、间接害死一名工人的真相。
```

## 核心戏剧问题

```text
顾岚能否在失去职业、家庭信任与自由的代价下，
阻止灾难重演，并把风险选择权交还给她一直试图保护的弟弟？
```

## 主题命题

```text
真正的负责，不是替别人挡住所有真相，
而是在真相代价最高时，仍让受影响的人拥有选择。
```

## 对立命题

```text
只要能避免更大损失，少数人的知情权和牺牲都可以被管理。
```

# 2. 第一性原理

## 2.1 主角发动机

| 项目 | 顾岚 |
|---|---|
| 外部目标 | 在风暴高潮前重启旧防潮隧道，打开疏散通路 |
| 内部需求 | 从“我独自承担，因此我可以隐瞒”转向“让受影响者知道并共同选择” |
| 错误信念 | “我当年隐瞒，是因为别人承受不了真相；现在也必须由我单独补救。” |
| 初始策略 | 绕过程序、独自潜入、使用技术能力、对弟弟和盟友隐瞒关键风险 |
| 最大恐惧 | 弟弟知道哥哥的死亡与她有关，并拒绝她 |
| 资源 | 港口结构知识、旧隧道图、调度中心旧证件、维修船驾驶经验 |
| 限制 | 停职、暴雨、旧伤导致手部力量不足、程野掌握她伪造报告的证据 |
| 失败代价 | 旧城区被淹；弟弟与居民被困；她再次以“保护”为名夺走他人的选择 |
| 高潮选择 | 公开伪造报告并把隧道控制权交给被困者代表顾川，接受自己无法控制所有后果 |

## 2.2 对抗力量发动机

| 项目 | 程野 / 失效防潮系统 |
|---|---|
| 外部目标 | 在风暴期间维持港口主航道与公司资产，避免旧隧道事故曝光 |
| 资源 | 调度权限、官方疏散广播、保安、气象数据、对顾岚旧案的了解 |
| 核心策略 | 将旧城区标记为“非优先区域”，诱导顾岚交出隧道图，再用她的旧罪迫使她沉默 |
| 限制 | 程野不能让旧隧道真正坍塌，否则公司责任无法掩盖；他需要顾岚的结构知识确认开门风险 |
| 盲点 | 他相信顾岚宁可自己背罪，也不会让弟弟知道真相 |
| 主题关系 | 把“风险管理”当成替他人决定可牺牲性的权力 |

## 2.3 关键关系

| 关系 | 开场状态 | 隐藏债务 | 核心冲突 | 终局变化 |
|---|---|---|---|---|
| 顾岚 / 顾川 | 疏离但相互依赖 | 顾岚隐瞒哥哥死亡真相；顾川隐瞒自己仍在旧城区工作 | 顾岚要控制风险；顾川要被当成有选择权的成年人 | 顾岚交出控制权；顾川知道真相后仍选择合作，但关系不再回到旧状态 |
| 顾岚 / 程野 | 前同事、彼此知底 | 程野利用顾岚的报告掩盖公司失职 | 一个想补救，一个想管理损失 | 顾岚公开文件，剥夺程野定义叙事的能力 |
| 顾岚 / 韩宁 | 旧救援搭档 | 韩宁曾替顾岚背过部分责任 | 韩宁拒绝再为顾岚的隐瞒买单 | 韩宁帮她，但条件是让顾川知道全部风险 |

# 3. 世界与规则

> 规则服务于人物选择，不能只是灾难片背景说明。

| ID | 规则 | 可做什么 | 不能做什么 | 代价 | 叙事用途 |
|---|---|---|---|---|---|
| R-01 | 旧防潮隧道只可从调度中心授权开启，现场只能手动维持开门 | 形成“远程权限 + 现场承担”双线 | 顾岚不能独自完成全部救援 | 必须让现场的人承担开门风险 | 迫使顾岚交出选择权 |
| R-02 | 风暴高潮前隧道仍可通行一次；高潮后水压会使门永久卡死 | 建立倒计时 | 不能无限重试 | 每次延误缩短窗口 | 让行动必须发生在今晚 |
| R-03 | 主航道与旧城区共用部分泵站容量 | 程野可以用“保护更多人”合理化关闭旧城区 | 他无法公开承认旧城区可被牺牲 | 每个选择都有真实损失 | 避免反派纯粹作恶 |
| R-04 | 旧事故报告的原始版本存于离线维修船终端 | 顾岚能证明真相 | 不能远程复制或即时公开 | 取证会耽误救援时间 | 迫使“救人或自证”两难 |
| R-05 | 顾岚的旧手伤在高压操作时会失力 | 限制她独自英雄化 | 她不能靠体力完成终局 | 需要他人接手关键操作 | 让关系成为动作的一部分 |

## 规则红线

```text
不可违反：
- 隧道不能凭一句密码立刻修好。
- 潮水和时间不会暂停等待人物完成情感谈话。
- 事故报告不能靠手机随手找到。
- 顾岚不能在高潮时突然恢复完美体力。

可被突破但必须付代价：
- 旧证件可以打开一次维护通道，但会留下访问记录。
- 维修船可绕开主航道，但会牺牲燃料与时间。
```

# 4. 因果脊柱

```text
旧状态：
顾岚在码头诊所做夜班维护，拒绝再参与港口安全事务；
她仍偷偷替顾川解决生活问题，却不告诉他哥哥死亡真相。

→ 触发事件：
暴雨预警升级，顾川所在旧城区被从官方疏散名单中移除；
顾岚发现旧防潮隧道被人为设为“不可用”。

→ 第一主动选择：
她用停职前保留的旧证件进入调度中心，盗取隧道状态图。

→ 第一次重大后果：
程野发现她仍在追查，并冻结旧城区的应急资源；
顾川因此无法按常规路线离开。

→ 中点翻转：
顾岚在维修船终端发现：当年导致哥哥死亡的伪造报告由她签字，
但程野利用该报告把旧城区永久降为低优先级。

→ 新策略：
她不再只想偷偷修好隧道；她决定夺取原始报告并重启隧道，
同时把程野的决策公开给所有被困者。

→ 第二次重大失败：
程野切断调度权限，韩宁受伤，顾岚发现顾川已进入隧道现场；
她若公开报告，就会让顾川知道自己参与过哥哥死亡事故。

→ 危机：
唯一能打开隧道的授权必须由调度中心和现场共同确认；
顾岚无法再单独决定谁承担风险。

→ 高潮选择：
她在全港广播中公开自己的签名与程野的原始指令，
把现场开门确认权交给顾川，让他和居民决定是否冒险开门。

→ 新常态：
隧道打开，旧城区部分获救，顾岚被带走调查；
顾川不原谅她，但把一份新的社区风险名单交给她，
邀请她在承担责任后继续参与修复系统。
```

# 5. 八序列大纲

> 八序列用于检查“每段是否改变问题、策略或风险”。
>
> 它不是要求每段严格等长。
>
> 每个序列结尾必须造成：
>
> ```text
> 目标变化
> 或策略变化
> 或资源/权力变化
> 或代价升级。
> ```

---

## 序列 1：被管理的风险

**预计时长：0–13 分钟**

### 任务

- 建立顾岚的旧策略：独自修补、小范围隐瞒、避免正式责任；
- 建立她与顾川的亲密/疏离；
- 建立港口公司将风险分类、分配的世界；
- 让异常风暴破坏旧常态。

### 节拍

| 编号 | 事件 | 顾岚目标 | 阻碍 | 结果/状态变化 |
|---:|---|---|---|---|
| 1 | 顾岚在码头诊所替渔工处理小伤，拒绝接听港口安全部来电 | 维持低调生活 | 韩宁提醒她风暴预警被上调 | 顾岚仍拒绝回港口 |
| 2 | 顾川来取药，假装只是路过 | 不让姐姐担心他仍在旧城区工作 | 顾岚发现他鞋上有防潮隧道的红泥 | 两人各自隐瞒一件事 |
| 3 | 港口广播宣布主航道优先疏散，旧城区“等待下一轮指令” | 顾岚想确认名单是否只是延迟 | 官方系统已把旧城区从优先名单移除 | 她意识到不是普通调度 |
| 4 | 顾岚查看旧城区泵站状态，看到隧道被标为“不可用” | 找到关闭原因 | 她没有权限 | 她拿出被封存的旧证件 |
| 5 | 顾川接到同事信息：旧城区出口开始积水 | 说服顾岚“不要插手” | 顾岚知道等待会错过窗口 | 顾岚决定重返调度中心 |

### 序列 1 结束点

```text
顾岚主动刷旧证件进入调度中心维护通道。

她从“我不再参与”转向“我必须私下解决”。
```

### 对抗审查

- 主角是否只是被风暴推动？  
  否。她先拒绝介入，再因名单和隧道状态主动违法进入调度中心。

- 为什么不是直接报警或公开？  
  她认为官方流程已被程野控制；这一判断部分正确，但也暴露她仍偏好独自行动。

- 是否过度解释世界？  
  否。用广播、泥土、泵站状态和名单变化呈现规则。

---

## 序列 2：旧门的钥匙

**预计时长：13–27 分钟**

### 任务

- 顾岚进入新冲突空间；
- 让程野作为理性且主动的对抗者出现；
- 建立“旧证件能开一次门，但会暴露位置”的规则；
- 把“救顾川”升级为“旧城区被系统性牺牲”。

### 节拍

| 编号 | 事件 | 顾岚策略 | 程野反制 | 结果 |
|---:|---|---|---|---|
| 6 | 顾岚进入调度中心后门，下载隧道状态图 | 用旧权限绕开前台 | 系统记录她的访问 | 她得到图，但暴露行踪 |
| 7 | 图上显示旧城区泵站被手动降级 | 找技术故障证据 | 程野远程锁定内部屏幕 | 顾岚只能记下关键参数 |
| 8 | 程野在调度室拦住她，称关闭是为了保护主航道 | 逼他承认旧城区可救 | 程野拿出她旧事故报告的副本 | 顾岚被迫承认自己也有污点 |
| 9 | 程野提出交易：交出旧隧道图，他给顾川一张船票 | 先保住弟弟 | 顾川并不在程野承诺的船票名单上 | 顾岚识破交易 |
| 10 | 顾岚偷走维修船泊位号，逃出调度中心 | 转向取原始报告 | 程野冻结旧城区应急资源 | 顾岚的行动直接让旧城区处境更差 |

### 序列 2 结束点

```text
顾岚拿到维修船位置，决定去取原始事故报告。
但程野以她的入侵为由冻结旧城区的应急资源。

她的“私下补救”已经产生公开后果。
```

### 第一幕锁定点验证

| 问题 | 结论 |
|---|---|
| 主角是否做出不可逆选择？ | 是，非法进入并盗取信息，已被记录。 |
| 她能否回到旧生活？ | 不能，程野掌握她行动与旧案。 |
| 目标是否更具体？ | 是，从“确认异常”变为“取原始报告并重启隧道”。 |
| 代价是否升级？ | 是，旧城区资源被冻结，顾川无法按常规路线撤离。 |

## 序列 3：救人还是自证

**预计时长：27–41 分钟**

### 任务

- 展示顾岚用旧策略行动；
- 让韩宁加入，但不是无条件盟友；
- 建立维修船、离线报告与时间成本；
- 让顾岚取得局部成功，却加深对顾川的隐瞒。

### 节拍

| 编号 | 事件 | 目标 | 阻碍 | 结果 |
|---:|---|---|---|---|
| 11 | 顾岚找到韩宁，请她开维修船去取报告 | 在高潮前拿到原始记录 | 韩宁拒绝再替她承担违规后果 | 顾岚答应“这次会告诉顾川” |
| 12 | 两人发现维修船燃料不足，只能走旧补给线 | 赶在潮水前到船上 | 旧补给线正在封闭 | 顾岚用结构知识打开临时通道，旧伤加重 |
| 13 | 船上终端读取出原始报告，但文件被加密为两部分 | 证明程野下令关闭隧道 | 第二部分存于隧道现场控制箱 | 顾岚只能先拿到自己的签名页 |
| 14 | 顾川打来电话，说旧城区居民开始自行往隧道聚集 | 让他撤离，别进隧道 | 顾川怀疑她知道更多 | 顾岚只说“相信我”，没有说真相 |
| 15 | 顾岚拿到报告副本，发现自己三年前的签名在首页 | 她开始隐瞒文件内容 | 韩宁看出异常 | 顾岚获得证据，也失去韩宁部分信任 |

### 序列 3 结束点

```text
顾岚拿到原始报告的一半：
它能证明程野做过什么，也能证明她曾经签过什么。

她选择把最关键的部分藏起来。
```

### 对抗审查

- 是否把韩宁写成万能帮手？  
  否。她提出条件、保留自己的风险判断，并因顾岚再次隐瞒而撤回信任。

- 局部胜利是否有代价？  
  是。顾岚得到报告，却失去时间、加重旧伤、加深与顾川和韩宁的谎言。

---

## 序列 4：中点——签名的真正用途

**预计时长：41–55 分钟**

### 任务

- 让顾岚对过去和当前危机有不可逆新理解；
- 改写主线：不是修好隧道，而是把被管理的风险公开；
- 将顾川从被保护对象变成潜在行动者。

### 节拍

| 编号 | 事件 | 旧理解 | 新理解 | 行动变化 |
|---:|---|---|---|---|
| 16 | 韩宁逼顾岚解释签名 | 顾岚以为签名只是她被程野胁迫的污点 | 她承认签名曾让哥哥所在维修班被延迟撤离 | 韩宁要求她告诉顾川 |
| 17 | 顾岚查看旧事故录音 | 她以为哥哥死亡是不可避免事故 | 录音显示程野故意将旧城区列为“可接受损失” | 程野不只是掩盖，而是在重复同一决策 |
| 18 | 顾川在隧道入口组织居民等待官方指令 | 顾岚以为只要把他带走就够了 | 顾川正在替所有人做决定，却没有完整信息 | 顾岚意识到自己和程野同样在剥夺知情权 |
| 19 | 程野公开广播：旧城区隧道结构不稳，禁止任何人进入 | 顾岚以为他只是拖延 | 他在制造顾岚“蛊惑居民冒险”的叙事 | 顾岚决定不再私下修复 |
| 20 | 顾岚把原始录音发给可信媒体联系人，但保留签名页 | 想公开程野而保护自己 | 媒体要求完整文件，否则不敢发布 | 她必须选择是否连自己一起公开 |

### 中点

```text
顾岚终于承认：
她当年不是单纯被逼签字，
```

| P1 | 时间预算需要专业一致性 | 单独建立分钟级行动时间线并咨询相关顾问 |
| P2 | “伪造报告”措辞可能过于概括 | 具体化为虚构安全分类报告，不提供现实流程细节 |
| P2 | 可加强顾岚开场的工作能力展示 | 通过诊所小型应急修理，展示她既专业又习惯越界代办 |

# 10. 从大纲到剧本的交接简报

```md
# 《潮线之下》Drafting Brief

## 不可改变的故事事实
- 顾岚曾签署导致旧城区撤离延迟的报告。
- 程野利用该报告持续把旧城区列为低优先级。
- 旧隧道必须远程授权与现场确认同时完成。
- 顾岚旧伤使她无法成为终局唯一执行者。
- 顾川必须在知情后自行决定是否确认开门。
- 高潮不以暴力击败程野，而以公开记录、集体知情和规则调用剥夺其控制。

## 主角弧
- 开场：以隐瞒换控制。
- 中点：认识到自己参与过同一套牺牲逻辑。
- 高潮：公开自证并交还选择权。
- 结尾：承担后果，不获得即时原谅。

## 必须出现的视觉锚点
- 防潮隧道红泥。
- 旧证件。
- 维修船离线终端。
- 顾岚右手旧伤。
- 哥哥留下的安全标记。
- 水位/倒计时的后期 UI。
- 最后公告板与记号笔。

## 制作原则
- 灾难优先通过局部水位、环境声音、警报、空间封闭、人物反应和后果表达。
- 不依赖大规模全景淹没或长镜头群体逃生。
- 所有可读屏幕内容后期合成。
- 高潮的物理行动必须与情感选择同步，但不把情感台词塞进每个动作点。
```

# 11. 最终原则

```text
长片不是把事件拉长。

它必须让主角的旧策略在越来越高的代价中显得合理、有效、然后失效；
让对手的反制既强大又合乎其目标；
让中点改变主角理解问题的方式；
让危机剥夺轻易选项；
让高潮成为主角终于愿意承担其最不愿承担之代价的行动。

若高潮只需要更大爆炸、更大追逐或突然援军，
而不需要主角做不同于开场的选择，
那么故事还没有完成。
```
