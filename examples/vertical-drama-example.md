# 竖屏微短剧样例：未登记的妹妹

> 原创开发样例。
>
> 用途：
>
> - 演示 `story-bible.md`、`vertical-episode.md`、`scene-card.md` 的实际填写方式；
> - 演示第一性原理：目标、阻碍、选择、后果；
> - 演示如何让前 5 秒、集内转折、集尾钩子和后续兑现形成因果链；
> - 演示低资产、可实拍或 AI 辅助制作的 9:16 方案。
>
> 本样例不应被视为唯一商业模板。
> 任何项目应先明确受众、平台、时长、支付模式、预算与内容边界。

---

# 1. 项目快照

| 项目 | 内容 |
|---|---|
| 项目名 | 《未登记的妹妹》 |
| 英文工作名 | *The Sister They Deleted* |
| 类型 | 都市悬疑 / 姐妹情感 / 身份危机 |
| 格式 | 竖屏连续微短剧 |
| 画幅 | 9:16 |
| 计划集数 | 36 集 |
| 单集时长 | 75–105 秒 |
| 核心受众 | 喜欢身份谜团、家庭债务、反抗权力与强关系线的移动端观众 |
| 主线 | 姐姐发现妹妹被城市数据系统从“合法存在”中删除，必须在系统自动清除前证明妹妹仍是一个人。 |
| 主要地点 | 合租公寓、数据服务大厅、地下停车场、医院走廊、旧档案室 |
| 主要角色 | 4 名常驻 + 少量功能性临时角色 |
| 制作方式 | 小空间实拍 / AI 辅助镜头 / 后期 UI 合成均可 |
| 内容边界 | 不以真实政府机构或真实身份数据库为原型；不展示可操作的违法入侵步骤。 |

## Logline

```text
当城市数据系统在 48 小时内将她妹妹林澈从所有公共记录中删除时，
背负伪造签名旧债的档案员林夏必须找到原始身份日志，
并对抗掌控系统的前上司周明；
否则妹妹会失去医疗、住处与法律身份，而林夏也将暴露自己当年参与伪造的真相。
```

## 核心问题

```text
林夏能否在拯救妹妹前，承认自己是妹妹被删除的最初原因之一？
```

## 主题命题

```text
保护亲人若建立在替他们决定真相的权力上，
最终会把保护变成另一种伤害。
```

## 对立命题

```text
只要结果是好的，隐瞒和控制就可以被原谅。
```

# 2. 第一性原理拆解

## 主角发动机

| 项目 | 林夏 |
|---|---|
| 外部目标 | 在 48 小时内找到并提交林澈的原始身份日志 |
| 内部需求 | 停止替妹妹决定“什么真相她承受得起” |
| 错误信念 | “我比她更能处理危险，所以我有权隐瞒。” |
| 初始策略 | 单独解决、利用旧关系、隐瞒自身责任 |
| 最大恐惧 | 妹妹知道自己曾参与删除程序后彻底离开 |
| 资源 | 档案系统工作经验、旧门禁卡、有限内部联系人 |
| 限制 | 已被停职；周明掌握她伪造签名的证据；时间只有 48 小时 |
| 高潮选择 | 公开自己参与过删除程序，放弃职业与法律安全，换取妹妹拥有知情权和证词权 |

## 对抗力量发动机

| 项目 | 周明 / “市民镜像”系统 |
|---|---|
| 目标 | 在系统升级前删除所有异常身份节点，避免旧项目曝光 |
| 资源 | 内部权限、监控记录、行政流程、林夏的旧违法证据 |
| 策略 | 先诱导林夏私下交出密钥，再把她塑造成异常事件责任人 |
| 限制 | 周明不能公开伪造原始日志；他需要林夏的旧权限才能完成彻底覆盖 |
| 盲点 | 他相信林夏永远会把妹妹排除在真相之外 |
| 与主题关系 | 将“保护秩序”当成控制他人命运的正当理由 |

## 最小因果链

```text
林澈的身份被系统标记为“待清除”
→ 林夏隐瞒真相并决定单独取回日志
→ 周明冻结她的内部权限，并要求交出旧门禁卡
→ 林夏偷取备用密钥，发现删除指令来自自己三年前的签名
→ 她继续隐瞒，导致林澈失去医院登记资格
→ 林澈开始怀疑姐姐，主动接触周明
→ 林夏必须在保住自己与告诉妹妹真相之间选择
→ 她公开签名记录，破坏周明的覆盖计划
→ 妹妹保住身份，但姐妹关系不再能回到“姐姐替她做决定”的旧模式。
```

## 为什么可持续 36 集

| 段落 | 集数 | 本段问题 | 局部兑现 | 新问题 |
|---|---:|---|---|---|
| 删除启动 | 1–6 | 林澈为何被删除？ | 林夏找回部分日志 | 指令竟来自林夏旧签名 |
| 旧债显形 | 7–12 | 林夏当年做了什么？ | 发现她曾救过林澈一次 | 她救人的方式伤害了别人 |
| 姐妹分裂 | 13–18 | 林澈还会相信林夏吗？ | 林澈知道部分真相 | 林澈转向周明寻求答案 |
| 证据争夺 | 19–27 | 原始日志在哪里？ | 找到物理备份 | 备份能证明周明，也能定罪林夏 |
| 公开代价 | 28–33 | 林夏会公开自己吗？ | 林夏交出证据 | 系统失效使更多人面临身份危机 |
| 新常态 | 34–36 | 姐妹如何在真相后重新相处？ | 林澈恢复身份 | 两人决定共同帮助其他“被删除的人” |

# 4. 世界规则

| ID | 规则 | 能做什么 | 不能做什么 | 代价 | 谁知道 |
|---|---|---|---|---|---|
| R-01 | “市民镜像”每晚 02:00 同步一次身份状态 | 让异常记录在多个服务端统一失效 | 不能改写实体档案室的离线原始日志 | 同步后恢复难度成倍增加 | 林夏、周明、少数内部员工 |
| R-02 | 系统标记为“待清除”后，医疗、支付、门禁等服务会分阶段失效 | 制造可见且递进的现实代价 | 不会让一个人突然物理消失 | 每次失效都会让林澈更难相信姐姐 | 林夏、林澈逐步得知 |
| R-03 | 旧门禁卡可开启档案室一次，但会留下访问日志 | 给主角一次行动窗口 | 不能修改、下载或抹除原始记录 | 使用后周明会立刻锁定林夏位置 | 林夏、周明 |
| R-04 | 原始日志必须由被记录人本人授权公开 | 避免林夏单方面“救人” | 林夏不能替林澈最终提交 | 林澈必须得知真相并做决定 | 林夏后知后觉，周明一直知道 |

> R-04 是主题规则：它使“林夏替妹妹处理一切”的旧策略在终局必然失败。

# 6. 完整单集样例：VE01《倒计时》

## 6.1 文档控制

| 字段 | 内容 |
|---|---|
| 集数 | VE01 |
| 集名 | 倒计时 |
| 时长 | 90 秒 |
| 剧情时间 | 第 0 天，19:10–19:18 |
| 画幅 | 9:16 |
| 主 POV | 林夏 |
| 地点 | 数据服务大厅外走廊 / 自助终端前 |
| 角色 | 林夏、周明、林澈（电话声音） |
| 关键道具 | 林夏手机、旧门禁卡、异常通知单 |
| 上集承接 | 系列首集，无前集 |
| 结尾交接 | 异常通知单、47:59:59 倒计时、林夏的伪造签名 |

## 6.2 本集一句话

```text
当林澈的身份被系统标记为“待清除”时，
林夏冲进数据大厅取回异常通知，
却被前上司周明拦住；
她虽然拿到通知，却发现删除指令使用的是自己三年前的签名。
```

## 6.3 本集唯一问题

```text
林夏能否在系统同步前确认妹妹到底遭遇了什么？
```

## 6.4 状态变化

```text
开场：
林夏以为妹妹只是遇到普通支付故障；
她仍相信自己能用内部经验快速处理。

结尾：
林夏知道林澈正被系统倒计时删除，
并发现自己与删除程序存在直接关联。
```

## 6.5 时长预算

| 段落 | 时长 | 功能 |
|---|---:|---|
| 入口钩子 | 0–8 秒 | 林澈在电话里说“医院说我不存在” |
| 目标成立 | 8–22 秒 | 林夏冲向终端，必须拿到异常通知 |
| 行动与阻碍 | 22–58 秒 | 门禁失效；周明现身要求她离开 |
| 转折 | 58–76 秒 | 林夏用旧卡强制打印通知 |
| 集尾钩子 | 76–90 秒 | 倒计时与她自己的旧签名出现 |

## 6.6 场景表

| 场次 | 时长 | 目标 | 阻碍 | 策略 | 转折 | 结束状态 | 视觉重点 |
|---:|---:|---|---|---|---|---|---|
| 1 | 42 秒 | 林夏确认林澈状态 | 终端拒绝访问；周明拦截 | 用旧员工身份强行进入 | 周明说出“你早该知道会有今天” | 林夏决定不走 | 林夏脸部、失效红字、周明从背景进入 |
| 2 | 48 秒 | 林夏拿到异常通知 | 强制打印会留下日志 | 刷旧门禁卡，抢走打印页 | 打印页显示倒计时与林夏签名 | 林夏从“救妹妹”变成“掩盖自己” | 门禁卡特写、打印纸、倒计时、签名页 |

# 7. VE01 场景脚本样例

> 本段为示范性短剧本，不追求完整技术格式。
>
> 每条动作只承担一个清楚的视觉任务；
> 不使用真实平台、机构、品牌或可操作的入侵步骤。

```text
内景 数据服务大厅外走廊 - 夜

林夏快步冲来，手机贴在耳边。画面中上部是她绷紧的脸。

林澈（电话）
医院说我不存在。

林夏停住。

林夏
你在哪？

林澈（电话）
门诊。挂号机把我名字删了。

林夏看向玻璃门内的自助终端。终端显示一行红字：

身份状态：待清除。

林夏挂断电话，刷工作证。

红灯。

身后，周明的声音平静。

周明
停职的人，进不去。

林夏没有回头。

林夏
她只是系统误判。

周明走进画面。两人的脸一前一后，占满竖幅。

周明
你比谁都清楚，
误判不会有倒计时。

林夏终于转身。

林夏
给我看通知。

周明伸手，像在索要她手里的旧门禁卡。

周明
把卡交出来。
我可以给她一个缓冲期。

林夏看向他手腕上的终端。屏幕反光里，倒计时跳动。

林夏
你不是在给缓冲期。
你是在等我认错。

她掏出旧门禁卡，贴上终端侧面的维护感应区。

提示音。

打印机吐出一张纸。

周明脸色第一次变了。

林夏抢过纸。

特写：待清除。剩余时间：47:59:59。
下方签发记录：林夏。三年前。

林夏的手指停在自己的名字上。

周明
现在你明白了。

林夏抬头。

林夏
不。
现在我知道你为什么怕我看见它。

切黑。
```

# 8. VE01 对抗式审查示范

## 8.1 目标、阻碍、选择、后果

| 元素 | VE01 答案 | 是否成立 |
|---|---|---|
| 主角目标 | 确认妹妹被系统做了什么 | 是，具体且可见 |
| 为什么现在 | 系统已开始 48 小时倒计时 | 是，时间压力明确 |
| 阻碍 | 终端拒绝访问；周明阻止；旧卡会留下日志 | 是，阻碍来自既有规则 |
| 主角选择 | 不接受周明的“缓冲期”，使用旧卡打印通知 | 是，主动且有代价 |
| 直接后果 | 周明锁定她仍有旧权限；林夏发现旧签名 | 是，改变后续风险 |
| 集尾问题 | 林夏为何签过删除指令？ | 是，具体、可追踪、可兑现 |

## 8.2 为什么钩子不是硬切

无效版本：

```text
林夏看到一张纸。
她瞪大眼睛。
屏幕变黑。
```

问题：

- 没有可读信息；
- 没有新状态；
- 没有下一集可验证的问题；
- 可以替换成任何悬疑剧的结尾。

有效版本：

```text
林夏主动刷卡
→ 留下访问日志
→ 拿到通知
→ 通知显示倒计时与她旧签名
→ 她从单纯救援者变成潜在责任人
→ 下一集必须回答：这份签名从何而来？
```

## 8.3 观众红队

| 问题 | 结论 | 修复需求 |
|---|---|---|
| 前 5 秒是否有风险？ | 有，“医院说我不存在”立刻制造身份危机 | 无 |
| 是否知道谁在乎什么？ | 知道，林夏担心妹妹；林澈已被现实服务拒绝 | 无 |
| 本集是否解释过多？ | 没有解释系统技术细节 | 无 |
| 是否至少兑现一个承诺？ | 确认“身份异常”是真实倒计时，不是普通故障 | 无 |
| 集尾是否明确？ | 明确，签名来自林夏 | 无 |

## 8.4 逻辑检察官

|---|---|---|

| 周明如何知道她会来？ | 异常通知先推送到林夏旧工作账号；这是他设下的观察点 | VE02 必须兑现 |

# 9. VE02《交卡》精简样例

## 本集问题

```text
林夏能否在周明提出交易时保住旧门禁卡？
```

## 因果链

```text
VE01 中林夏使用旧卡，周明确认她仍有权限
→ 周明要求她用门禁卡换妹妹的“缓冲期”
→ 林夏假装同意，试图在离开前复制通知上的编号
→ 周明拿出三年前签名页，证明她并不只是旁观者
→ 林夏保住门禁卡，但周明知道她会去旧档案室
→ VE03：林夏必须赶在周明之前进入档案室。
```

## 75 秒节拍

| 时间 | 节拍 | 状态变化 |
|---:|---|---|
| 0–7 秒 | 承接 VE01：周明看着林夏手中的签名页 | “签名”不是幻觉，风险真实 |
| 7–22 秒 | 周明提出交易：交卡，给林澈 24 小时缓冲 | 林夏获得错误的简易选择 |
| 22–45 秒 | 林夏假装同意，靠近周明终端读取编号 | 她从防守转为试探 |
| 45–60 秒 | 周明翻出三年前完整签名页 | 周明夺回信息优势 |
| 60–75 秒 | 林夏拿走门禁卡离开；周明对监控说“她会去 B-17” | 她保住资源，但行动被预判 |

## VE02 结尾钩子

```text
周明并不追林夏。
他只是对监控镜头说：

“她会去 B-17。”

林夏在走廊尽头停住。
她意识到：周明知道她唯一会去的地方。
```

### 钩子验证

```text
林夏选择保住门禁卡
→ 唯一合理行动是去旧档案室
→ 周明准确预判
→ 档案室不再是安全答案，而可能是陷阱
→ VE03 必须快速兑现：她到底还去不去？
```

# 10. VE03《签名》精简样例

## 本集问题

```text
林夏为什么在三年前签过删除指令？
```

## 局部兑现规则

上一集承诺：周明预判林夏会去 B-17。

本集前 15 秒必须提供回报：

```text
林夏仍去了 B-17，
但她先用废弃通道进入，
证明她不是无视风险，而是改变了策略。
```

## 本集核心转折

```text
林夏发现当年签名并非为删除林澈，
而是为了将林澈从一份“集体异常名单”中单独剥离。

她当年救了妹妹，
却让名单上另一个人承担了后果。
```

## 集尾钩子

```text
原始日志里出现第二个名字：陈昱。

镜头切到医院信息科。
陈昱正在给一张病历盖章。
系统弹窗：身份状态异常。

病历患者姓名：林夏的母亲。
```

> 该钩子不是随机增加新危机：它连接林夏旧签名、陈昱身份、系统异常扩散和家庭代价。

# 11. 样例中故意避免的失败机制

| 失败机制 | 常见写法 | 本样例的替代 |
|---|---|---|
| 随机 cliffhanger | 门响、角色瞪眼、切黑 | 钩子来自人物行动后的新状态 |
| 付费后拖延 | 下一集先 recap 40 秒 | 下一集前 5–15 秒确认后果并进入新行动 |
| 主角被动 | 不断收到新文件 | 林夏每集都要选择：取、瞒、换、逃、公开 |
| 反派万能 | 周明什么都能做到 | 周明需要林夏旧权限，且不能公开原始日志 |
| 技术魔法 | 系统随时做到任何事 | 每条系统规则有能力、限制和代价 |
| 误会拖集数 | 姐妹一直不说真话 | 隐瞒每次都造成具体资源/关系代价，并逐步缩短 |
| 重复羞辱 | 每集只让主角被打压 | 每集改变权力、信息、资源或关系至少一项 |
| 超支资产 | 每集新豪宅、新公司、新群演 | 固定五个可复用地点，核心为近景关系与关键道具 |
| AI 文字风险 | 直接生成可读 UI | 所有通知、倒计时、病历等后期合成 |
| AI 动作风险 | 长镜头追逐、复杂打斗 | 利用门禁、走廊、打印纸、手部特写和反应镜头制造张力 |

# 14. 反例：把 VE01 写坏会怎样

## 失败版本

```text
林澈给林夏打电话，说自己很害怕。
林夏解释系统很复杂。
周明出现，说：“你妹妹要被删除了！”
林夏震惊。
周明笑。
切黑。
```

## 为什么失败

| 问题 | 后果 |
|---|---|
| 主角没有行动 | 林夏只是接收信息 |
| 反派解释剧情 | 周明变成信息投递员 |
| 系统风险不可见 | 观众无法判断“删除”意味着什么 |
| 没有资源与代价 | 林夏没有必须冒险的选择 |
| 结尾无状态变化 | “震惊”不等于新剧情状态 |
| 下一集不明确 | 观众只知道“有危险”，不知道要看什么 |

## 最小修复

```text
让林夏必须选择：
接受周明的缓冲交易，
或使用旧卡拿到真相并暴露自己。

让结尾证据改变她的身份：
她不再只是救援者，
而成为与删除指令有关的人。
```

# 15. 使用本样例的方法

## 若改造成爱情复仇题材

保留：

```text
具体目标
+ 对手反制
+ 主角秘密
+ 关系权力变化
+ 代价性钩子
```

替换：

```text
“身份删除系统”
→ “婚前财产信托 / 身份伪造 / 家族继承程序”

“原始日志”
→ “遗嘱附件 / 监控备份 / 亲子鉴定原件”
```

但不得只替换名词。

仍须回答：

- 主角每集具体要得到什么？
- 对手为什么不能让步？
- 主角每次行动的代价是什么？
- 钩子承诺什么，下一集如何兑现？
- 关系如何因行动而改变？

## 若扩展为 60 集

不要简单加：

```text
更多误会
更多失忆
更多突然亲属
更多绑架
更多身份反转
```

应增加：

```text
新的因果层：
林夏的旧签名不仅改变林澈，也伤害其他被系统剔除的人；
林澈从被保护者变成掌握原始授权的人；
周明必须在系统稳定与自我保全之间做选择；
姐妹关系从依赖走向共同承担。
```

# 16. 最终原则

```text
竖屏短剧的“快”不是让人物更快说话，
也不是每 30 秒塞入一个无因反转。

快是：
观众快速读懂谁在乎什么；
人物快速采取行动；
阻碍快速让旧策略失效；
后果快速改变状态；
下一集快速兑现上一集承诺。

真正的留存不是靠把答案藏起来，
而是靠每次给出答案后，
都让人物不得不面对一个更有代价的新问题。
```
