# 对抗式剧本审查量表

> 本文件是 `professional-screenwriter` 的按需参考资料。
>
> 当用户要求审稿、剧本诊断、Script Doctor、红队、挑刺、对抗式审查、ultrathink、重写方案、绿灯评估、制作可行性审查时加载。
>
> 本文件的目标不是给出“好不好看”的主观印象，而是主动寻找：
>
> ```text
> 观众会在哪一刻退出？
> 逻辑会在哪一处断裂？
> 人物会在哪一刻失去可信度？
> 制作会在哪一个环节失控？
> 以及如何以最小改动修复最大问题。
> ```
>
> 主 `SKILL.md` 的安全、版权、人物主动性、因果、连续性和内容边界规则优先于本文件。

# 1. 第一性原理

## 1.1 审查不是赞美或挑错表演

无效审查：

```text
整体不错。
节奏可以更紧凑。
人物不够立体。
建议加强情感。
有潜力。
```

这些判断没有：

- 证据；
- 严重等级；
- 失败机制；
- 修复动作；
- 验证方式。

有效审查必须满足：

```text
具体证据
→ 失败机制
→ 观众/人物/制作后果
→ 最小可行修复
→ 连锁影响
→ 修复后复测
```

---

## 1.2 审查的对象是“承诺是否被兑现”

任何剧本都向观众作出至少五类承诺：

| 承诺 | 观众隐性问题 |
|---|---|
| 前提承诺 | 这个故事为什么值得看？ |
| 人物承诺 | 我为什么关心这个人？ |
| 因果承诺 | 事件为什么会这样发生？ |
| 类型承诺 | 我会获得什么体验？ |
| 结局承诺 | 前面铺垫最终会得到怎样的回报？ |

对抗审查的核心，不是检查作品是否“符合模板”，而是检查：

```text
剧本建立了什么期待？
它是否有能力兑现？
它是否用公平、因果且有代价的方式兑现？
```

---

## 1.3 证据优先

任何批评都必须引用以下至少一种证据：

- 场次号
- 集数与场次
- 页码或段落
- 明确的事件
- 明确人物选择
- 明确台词
- 明确道具、时间线或信息状态
- 明确镜头/资产要求

禁止假装读过未提供的文本。

若文本不完整，使用：

```text
基于当前提供范围的判断：
待验证假设：
无法判断的部分：
```

不要将推测写成事实。

# 2. 审查启动与范围

## 2.1 启动条件

以下情况必须执行对抗式审查：

- 完成 Logline、梗概、故事圣经或结构大纲；
- 完成分集目录；
- 完成某集、某场或完整初稿；
- 完成重大重写；
- 项目准备投递、融资、拍摄、AI 批量生成或平台上线；
- 用户要求“审稿”“红队”“挑刺”“ultrathink”“找漏洞”。

## 2.2 审查范围声明

审查前先写：

```md
# 审查范围

- 项目名称：
- 版本：
- 材料类型：Logline / 梗概 / 大纲 / 分集 / 剧本 / 分镜 / 制作包
- 已审范围：
- 未审范围：
- 目标格式：
- 目标观众：
- 已知制作约束：
- 评审目的：开发 / 改稿 / 投递 / 制作 / 上线
- 审查标准：
- 结论可信度限制：
```

没有范围声明的审查，容易将不同格式、不同目标和不同版本混为一谈。

# 3. 评审角色

必须从以下四种独立立场审查。不可将其合并成泛泛反馈。

## 3.1 怀疑观众

假设观众没有耐心、可随时退出。

问题：

- 我在何时不知道谁想要什么？
- 我为什么要关心主角？
- 我在何时感到重复、拖延或可预测？
- 我是否误把困惑当成悬念？
- 这一场结束后，我是否真的想看下一场？
- 类型承诺是否被满足？
- 情绪回报是否被挣得？

核心风险：

```text
困惑
无聊
重复
期待落空
情感脱离
被欺骗感
```

## 3.2 逻辑检察官

假设任何漏洞都会被观众发现。

问题：

- 每个关键事件是否由前一选择或后果导致？
- 人物是否知道自己不该知道的信息？
- 时间、空间、资源、伤病、道具和证据是否连续？
- 世界规则是否随剧情需要而改变？
- 人物是否有更直接、更合理却被剧本忽略的选项？
- 对手如果聪明一点，当前计划还能成立吗？
- 巧合是否解决了主要问题？

核心风险：

```text
因果断裂
信息越界
规则漂移
人物失智
巧合解题
时间线矛盾
```

## 3.3 人物辩护人

假设人物不是作者的木偶。

问题：

- 人物在此刻想要什么？
- 他/她为什么用这个策略？
- 该策略是否符合其知识、资源、恐惧和底线？
- 人物是否只在剧情需要时突然变聪明或变愚蠢？
- 主角是否主动创造变化，还是只被事件推动？
- 对手是否具有目标、资源与适应能力？
- 人物的改变是否经过压力、失败和代价？

核心风险：

```text
作者强迫行为
动机缺失
人物同声
被动主角
工具人反派
未挣得的人物弧
```

## 3.4 制作与风险制片人

假设预算、模型能力、法律和上线条件都是真实限制。

问题：

- 这部作品的生产价值在哪里？
- 成本是否与故事收益匹配？
- 是否存在不必要的群众、动物、未成年人、复杂动作、特效、真实品牌或跨国场景？
- AI 视频是否能稳定维持角色、道具、空间和口型？
- 是否存在敏感内容、肖像、版权、商标、诽谤、文化或平台风险？
- 是否有更低成本但保留叙事结果的替代方案？
- 是否存在上线后无法解释或修复的风险？

核心风险：

```text
资产爆炸
不可控动作
连续性崩坏
权利不清
内容敏感
预算失配
交付失败
```

## 3.5 领域适配与横切检查

四个角色不变；以下内容是尺度与载体适配，不新增第五个评审角色：

- **场景级**：怀疑观众检查入场是否过早、离场是否过晚和退出状态；逻辑检察官检查每个
  关键行动的前置事实、空间方向与更简单方案；人物辩护人检查 POV 选择及关系变化是否由
  行动挣得；制作与风险制片人检查画幅、可替代动作、顾问和法务需求。
- **分集级**：怀疑观众检查前 15 秒、本集问题、最早退出点、局部回答与集尾下一问；
  逻辑检察官检查前后集知识、时间、道具、伤病与规则连续；人物辩护人检查本集主动选择
  和人物弧；制作与风险制片人检查新增资产、预算、AI 与连续性风险。
- **Story Bible 级**：检查主角—目标—对手—代价能否复述，承诺是否可兑现，核心节点能否
  用“因此/但是”连接，人物状态机是否支持改变，以及资产、地点、角色和权利边界是否可维护。
- **竖屏短剧**：制作角色额外检查手机可读性、脸/手/关键道具优先级、远景/群像/小字 UI、
  单一主体—动作—焦点与跨集资产稳定性。

两项横切检查仍向四角色归责：

- **节奏编辑**：检查能否更晚进入、更早离开，是否重复同种冲突、无效支线或没有状态变化
  的中段；Finding 按观众流失、因果/信息位置或制作时长归入对应角色。
- **信任守门人**：检查钩子是否有前置因果、延迟是否给初步回报、付费后是否真实兑现、
  是否用重复反转或人物失智拖集；Finding 主要归入怀疑观众，并按因果或人物机制交叉标注。

# 4. 审查流程

## 4.1 四轮顺序

按以下顺序执行，禁止一开始就改台词：

```text
第一轮：前提与目标
第二轮：因果与结构
第三轮：人物与关系
第四轮：场景、对白、格式与制作
```

原因：

```text
前提不成立时，精修台词没有意义。
因果不成立时，优化节奏只是掩盖问题。
人物不成立时，反转只会显得作者操控。
制作不可行时，漂亮剧本无法交付。
```

## 4.2 两遍阅读法

### 第一遍：体验阅读

不暂停过度分析，记录即时反应：

```md
| 位置 | 即时反应 | 触发原因 | 可能风险 |
```

记录：

- 何时投入；
- 何时困惑；
- 何时预判；
- 何时情绪被触动；
- 何时注意力下降；
- 何时觉得信息缺失；
- 何时觉得人物行为不对。

### 第二遍：取证阅读

将第一遍反应转为可验证问题：

```md
| 问题 | 证据位置 | 违反的叙事规则 | 严重度 | 修复方向 |
```

不要把第一次阅读的个人口味直接写成必须修改的结论。

# 5. 严重度体系

## 5.1 P0：阻断级问题

定义：

```text
若不修复，故事无法被理解、人物无法被相信、
结局无法成立，或制作/合规无法推进。
```

典型情况：

- 主角没有明确目标；
- 主线因果断裂；
- 高潮由巧合或外部救援解决；
- 核心人物行为无动机；
- 时间线或世界规则导致故事自相矛盾；
- 付费后关键承诺长期不兑现；
- 使用无授权真实人物、声音或版权内容；
- AI 制作关键镜头无法稳定实现且无替代。

处理规则：

- 必须优先修复；
- 不建议在 P0 未处理前润色对白；
- 每个 P0 必须有最小修复与连锁影响分析；
- 如用户决定保留，必须标记为“已接受风险”。

## 5.2 P1：重大问题

定义：

```text
不阻断故事基本成立，
但显著降低观看、人物、节奏、商业或制作质量。
```

典型情况：

- 中段重复；
- 对手不够主动；
- 关键关系缺少推进；
- 钩子强行中断；
- 支线未服务主线；
- 台词同声化；
- 资产和场景过多；
- 结局情绪回收不足。

处理规则：

- 在 P0 后优先处理；
- 需要明确修复策略；
- 修复后复测对节奏与连续性的影响。

## 5.3 P2：优化问题

定义：

```text
不影响基本可用性，但改善后可提升清晰度、特色、效率或体验。
```

典型情况：

- 个别台词可更简洁；
- 次要道具可更有象征性；
- 某场进入可更晚；
- 某个角色声音可更鲜明；
- 个别视觉母题可增强。

处理规则：

- 只在 P0/P1 关闭后处理；
- 不得因 P2 修改引入新的 P0/P1。

# 6. 评分框架

## 6.1 使用方式

每个维度按 0–5 分评估。

评分不是数学真理，而是帮助识别薄弱环节。

每个分数必须附：

- 证据；
- 失败机制；
- 影响范围；
- 优先级；
- 修复方向。

## 6.2 分数含义

| 分数 | 含义 |
|---:|---|
| 0 | 缺失、矛盾或不可用 |
| 1 | 严重失效，阻断理解或信任 |
| 2 | 存在基础，但大量不稳定或重复 |
| 3 | 基本成立，存在清晰可修复问题 |
| 4 | 强，有少量局部问题 |
| 5 | 明确、稳定、有独特性且经得起反证 |

不要因“整体喜欢”就给所有项目 4–5 分；
也不要因题材不合个人喜好就给低分。

## 6.3 核心评分矩阵

| 维度 | 核心问题 | 典型失败信号 |
|---|---|---|
| 前提与 Logline | 为什么值得看？ | 无目标、无代价、不可复述 |
| 类型与受众 | 承诺是否清晰？ | 类型混乱、受众不明 |
| 主角主动性 | 谁推动故事？ | 主角只被动反应 |
| 欲望与风险 | 失败会怎样？ | 代价抽象或不升级 |
| 因果链 | 为什么发生？ | “然后”多于“因此/但是” |
| 结构 | 故事是否逐层升级？ | 中段松散、高潮突兀 |
| 场景功能 | 每场是否必要？ | 状态不变、信息重复 |
| 人物动机 | 行为是否可信？ | 为剧情而行动 |
| 人物弧 | 改变是否挣得？ | 结尾突然觉醒 |
| 对手系统 | 阻碍是否主动？ | 反派只会等着失败 |
| 关系线 | 权力/信任是否变化？ | 误会循环、关系静止 |
| 信息管理 | 知识差是否清楚？ | 困惑、硬反转 |
| 对白 | 是否有行动、差异和潜台词？ | 同声、解释、口号 |
| 主题 | 是否被选择检验？ | 只靠台词宣讲 |
| 节奏 | 张弛与兑现是否合理？ | 重复、拖延、无呼吸 |
| 格式与可读性 | 是否快速、可拍、可协作？ | 小说化、格式混乱 |
| 生产价值 | 是否有可见且合理的亮点？ | 低成本却无特色，或高成本无收益 |
| 可制作性 | 是否能在约束内实现？ | 资产爆炸、复杂动作 |
| 连续性 | 时间、道具、信息是否一致？ | 前后矛盾、规则漂移 |
| 安全与权利 | 是否有内容/权利风险？ | 未授权肖像、敏感风险 |

# 7. 分维度审查问题

## 7.1 前提与 Logline

检查：

- 是否能在一句话中说清主角、触发事件、目标、阻碍和代价？
- 前提是否包含可持续的冲突，而非仅一个背景设定？
- 主角是否是最适合承受该前提压力的人？
- 是否有可复述的独特视角？
- 是否承诺了与类型相匹配的体验？

反证：

```text
如果替换主角，故事是否不变？
如果去掉高概念标签，是否还剩冲突？
如果把触发事件删掉，主角是否仍会做同样的事？
```

## 7.2 欲望、风险与主动性

检查：

- 主角现在想要什么？
- 目标是否具体、可见、可计时？
- 失败代价是否具体、可感、会升级？
- 主角是否至少在早期做出一个有代价的选择？
- 主角是否在失败后改变策略？

反证：

```text
主角什么都不做，故事是否仍会几乎一样发生？
如果是，主角缺乏主动性。
```

## 7.3 因果链与世界规则

检查：

- 每个重大事件是否由前一行为、选择或规则引发？
- 是否出现“因为作者需要”而存在的事件？
- 规则是否有明确边界、成本与后果？
- 是否有角色掌握不应掌握的信息？
- 是否有关键资源在需要时突然出现？

反证：

```text
将每个“然后”替换为“因此”或“但是”。
无法替换的段落，通常缺少因果。
```

## 7.4 结构与中段

检查：

- 触发事件是否破坏旧常态？
- 主角是否主动进入冲突？
- 中点是否改变目标、权力、认知或风险？
- 危机是否消除了轻易选项？
- 高潮是否由主角变化后的选择推动？
- 结局是否展示真实代价？

反证：

```text
删除中间 20%–30% 内容后，人物策略和关系是否仍不变？
如果是，中段可能无效。
```

## 7.5 人物与人物弧

检查：

- 每个主要人物是否具有目标、恐惧、资源、盲点和策略？
- 人物是否在压力下作出独特选择？
- 改变是否来自连续失败、关系冲突和代价？
- 人物是否只在需要时才拥有技能、信息或勇气？
- 次要角色是否仅作为送信息、被拯救或制造误会的工具？

反证：

```text
如果把两个配角合并，主线是否更清晰？
如果替换人物姓名，台词和行动是否仍完全成立？
```

## 7.6 对手与冲突

检查：

- 对手想要什么？
- 对手为何有能力阻止主角？
- 对手如何根据主角行动学习与反击？
- 对手是否攻击主角最深的错误信念或软肋？
- 冲突是否从外部事件升级到价值和选择？

反证：

```text
如果对手采取最有效策略，主角的计划是否立即失效？
若是，主角需要更聪明的策略，或对手需要合理限制。
```

## 7.7 场景功能

检查每场：

```text
谁想要什么？
谁反对？
采用什么策略？
发生何种转折？
退出时状态改变了什么？
```

反证：

```text
删除本场后，主线、人物、主题或制作是否损失关键内容？
若没有，删除、合并或重写。
```

## 7.8 信息、谜团与反转

检查：

- 观众是否知道当前最重要的问题？
- 是好奇、悬念、惊奇，还是单纯困惑？
- 反转是否有前文线索？
- 信息延迟是否制造压力，而非拖延？
- 秘密被揭露后是否迫使人物改变行动？

反证：

```text
观众提前猜到反转后，是否仍有情绪或人物价值？
如果完全没有，反转只靠信息遮挡。
```

## 7.9 对白

检查：

- 每句对白的行动动词是什么？
- 是否反映说话者的背景、关系权力和即时策略？
- 人物是否说出双方已经知道的事情？
- 对白是否能被行为、沉默或物件替代？
- 是否存在长篇解释、金句堆叠或同声化？

反证：

```text
删除每句对白后，关系、信息或行动是否改变？
若不改变，删去或合并。
```

## 7.10 主题与情绪

检查：

- 主题能否以可被验证的命题表达？
- 不同人物是否给出不同答案？
- 主题是否通过行动和代价呈现？
- 情绪高潮是否由人物选择挣得？
- 是否避免将主题变成说教？

反证：

```text
拿掉所有主题台词后，观众还能从选择中推断主题吗？
若不能，主题未进入剧情。
```

## 7.11 节奏与钩子

检查：

- 进入场景是否太早，离开是否太晚？
- 是否存在重复冲突、重复羞辱、重复误会？
- 是否有局部胜利、呼吸和新的代价？
- 钩子是否来自因果而非随机中断？
- 下一场/下一集是否合理兑现承诺？

反证：

```text
将同类冲突压缩为一场，故事是否更有力？
若是，存在重复。
```

## 7.12 制作、权利与安全

检查：

- 是否存在不必要的高成本场景、群众、动物、特效或复杂动作？
- 是否可用声音、反应、局部细节或合成保留叙事结果？
- 是否使用真实人物、品牌、地点、制服、声音、音乐或文本？
- 是否涉及未成年人、性、暴力、自残、歧视、违法或仇恨表达？
- 是否需要法务、平台、医疗、警务、文化或行业顾问核验？

反证：

```text
降低 30% 资产和复杂度后，核心人物选择是否仍成立？
若成立，当前方案可能未优化。
```

# 8. 反证测试库

审查时至少选择 5 个适用测试。

## 8.1 删除测试

```text
删除这个角色 / 场景 / 道具 / 支线，会失去什么？
```

若答案是“感觉会少一点内容”，通常应该删除或合并。

## 8.2 反向选择测试

```text
如果主角做出相反选择，故事是否更合理或更有冲突？
```

若是，当前选择缺乏动机、代价或人物特性。

## 8.3 聪明对手测试

```text
如果对手具备正常智力和资源，主角当前计划还能成立吗？
```

若不能，补充主角策略、对手限制或代价。

## 8.4 信息公开测试

```text
如果人物说出本应说出的真相，故事是否立刻结束？
```

若是，必须建立真实的隐瞒理由，例如风险、利益、羞耻、法律、信息不确定或关系后果。

## 8.5 去巧合测试

```text
去掉巧合、突然援军、临时证据或随机事故，高潮还能发生吗？
```

若不能，重建前文因果。

## 8.6 预测测试

```text
观众在反转前是否已经有合理线索？
观众猜到后，故事是否仍有体验价值？
```

若没有线索，是欺骗；
若猜到便无价值，是单薄。

## 8.7 压缩测试

```text
将两场相似冲突合并，会损失什么？
```

若损失不大，节奏存在冗余。

## 8.8 代价测试

```text
主角赢得目标时，真正失去或承担了什么？
```

若答案是“几乎没有”，结局可能廉价。

## 8.9 格式替换测试

```text
将该故事改成短片、电影或剧集后，是否反而更自然？
```

若是，当前载体可能错配。

## 8.10 制作降级测试

```text
用更少角色、地点、动作和特效，是否仍能传达同样的选择和后果？
```

若是，优先采用可控方案。

# 10. 推荐结论

## 10.1 RECOMMEND

可进入下一阶段。

条件：

- 没有未处理 P0；
- 核心前提、人物、因果、结构和结局均稳定；
- 关键制作与权利风险可控；
- 剩余问题多为 P2 或局部 P1；
- 作品的独特价值可清楚表达。

## 10.2 CONDITIONAL_RECOMMEND

值得继续开发，但需要明显改稿。

条件：

- 核心具有价值；
- 存在可修复 P1；
- 没有无法解决的根本前提问题；
- 修复路径明确；
- 不应直接进入制作或公开发行。

## 10.3 REWRITE

仅在明确完成特定修订后继续。

条件：

- 有 1–3 个关键 P0；
- 这些问题可在不推翻项目核心的前提下修复；
- 需要先验证结构、人物或制作方案；
- 不建议同时做表层润色。

## 10.4 REJECT

当前版本不建议继续投入。

适用情况：

- 前提缺乏可持续冲突；
- 主角、目标或代价长期不清；
- 因果、人物和结局存在不可修复的系统性问题；
- 项目与格式严重错配；
- 制作、版权或内容风险无法接受；
- 修复成本超过保留现有版本的价值。

`REJECT` 不等于创作者没有能力；它意味着当前版本不适合沿原路径继续投入资源。

# 11. 重写优先级

固定顺序：

```text
P0 前提 / 主角 / 代价
→ P0 因果 / 结构 / 高潮
→ P1 人物 / 对手 / 关系
→ P1 场景 / 信息 / 节奏
→ P2 对白 / 格式 / 视觉细节
```

禁止：

```text
结构不成立
→ 先改台词
→ 加更多反转
→ 加更多设定
→ 让问题更复杂
```

每轮重写只设一个主要目标。

示例：

```md
本轮目标：
让主角在中点主动选择公开部分证据，
从而失去工作与盟友，并迫使对手公开反击。

本轮不处理：
幽默台词、场景描写、次要角色口音、配乐建议。
```

---

# 12. 复审协议

## 12.1 重写后不得自我宣布成功

每次重写后重新检查：

- 修复是否真的解决原问题？
- 是否引入新的因果漏洞？
- 是否削弱主角主动性？
- 是否破坏人物动机？
- 是否让对手变笨？
- 是否制造新的连续性问题？
- 是否增加不必要制作成本？
- 是否仅把问题移动到更后面？

## 12.2 P0 关闭条件

一个 P0 只有满足以下条件才可关闭：

- 已修改对应结构、场景或人物选择；
- 修复前后的因果差异可解释；
- 相关人物动机保持一致；
- 受影响的后续场景已更新；
- 连续性日志已更新；
- 对抗测试已重新运行；
- 未出现新的同等级问题。

## 12.3 复审表

```md
# 复审记录

| 问题 ID | 原问题 | 修改内容 | 复审结果 | 新风险 | 状态 |
|---|---|---|---|---|---|
```

状态：

```text
OPEN
IN_PROGRESS
FIXED
ACCEPTED_RISK
REGRESSED
```

# 13. 不应做的事

审查时禁止：

- 假装读过未提供的剧本；
- 用个人审美偏好冒充客观错误；
- 只批评不提供修复方向；
- 用“节奏不好”代替指出具体场景与重复机制；
- 强迫所有故事使用三幕式、英雄之旅或单一类型模板；
- 将商业类型片天然视为低级，或将艺术表达天然视为高级；
- 为了“更刺激”牺牲人物尊严、逻辑或内容边界；
- 为了“更好拍”删除关键人物选择；
- 把制作预算、法律、平台政策当作已知事实而不核验；
- 把评分表当成替代真实阅读与判断的机器。

# 14. 与其他参考文件协作

## 14.1 微短剧

读取：

```text
short-drama-playbook.md
hook-paywall-engine.md
```

额外检查：

- 前 15 秒入口钩子；
- 每集局部目标、反转和状态变化；
- 集尾钩子是否因果成立；
- 付费后兑现是否及时；
- 是否存在重复羞辱、重复误会和强行拖集数。

## 14.2 长短片与剧集

读取：

```text
film-series-format.md
```

额外检查：

- 当前格式是否与故事规模匹配；
- 短片是否承载了过多支线；
- 长片中点是否改变行动语法；
- 剧集是否兼具集级满足和季级推进；
- 季终是否回答季级问题。

## 14.3 剧本格式

读取：

```text
screenplay-format-cn-en.md
```

额外检查：

- 场景标题、人物名称、动作、对白与声音标记是否统一；
- 是否混入过多不可拍内心、镜头指令或小说化描写；
- Fountain 或导出格式是否实际验证。

## 14.4 AI 制作

读取：

```text
ai-production-handoff.md
```

额外检查：

- 剧本是否已锁定；
- 资产、角色、服装、道具和空间能否连续；
- 镜头是否单一目标、单一动作；
- 是否把模型不擅长的任务拆分或后置；
- 是否存在未经许可的人脸、声音、品牌或文本。

# 15. 最终原则

审查不是为了证明审查者聪明，而是为了让作品在真正的观众、读者、制片、演员、平台和制作流程面前更不容易失败。

最终判断顺序始终是：

```text
故事是否清楚？
人物是否可信？
选择是否有代价？
因果是否成立？
承诺是否兑现？
能否被安全、合法、可控地制作？
```

如果答案是否定的，优先修复最深层的问题；
不要用更多设定、更长台词、更大反转或更华丽画面覆盖它。
