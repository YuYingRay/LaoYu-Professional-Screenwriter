# 1. 第一性原理

## 1.1 格式不是时长标签

短片、电影和剧集的根本差异，不是“字数”或“场景数量”，而是观众愿意为哪一种问题持续投入注意力。

| 格式 | 观众主要投资 | 核心叙事问题 |
|---|---|---|
| 概念超短片 | 一个有力的想法或感受 | “这个前提意味着什么？” |
| 叙事短片 | 一次完整的人物变化 | “此刻的选择会如何改变此人？” |
| 电影长片 | 一段不可逆的人生旅程 | “他/她能否在代价中完成核心选择？” |
| 单集剧 | 一个可相对独立的冲突 | “这一集的问题如何解决或转化？” |
| 连续剧 | 持续升级的关系与谜团 | “主线会把人物带向哪里？” |
| 季播剧 | 多条人物线共同改变一个世界状态 | “这一季结束时，什么再也回不去了？” |

因此，不要将长片裁成许多短集，也不要将短片强行补成电影。

---

## 1.2 格式选择公式

在进入写作前，用以下问题判断格式：

```text
故事真正需要承载的是：
一个观点？
一次选择？
一段人生变化？
一个可每周更新的案件/问题？
还是一套可持续升级的关系与世界？
```

判定规则：

- 如果故事的力量主要来自一个画面、一个设问或最后一击，优先考虑概念超短片。
- 如果故事只需要让一个人物在一个关键时刻改变或失败，优先考虑叙事短片。
- 如果主角必须经历多次主动尝试、失败、认知反转和价值选择，才考虑电影。
- 如果每一集都能独立提出并处理一个局部问题，同时推动更大主线，考虑剧集。
- 如果只有一个结局、没有可持续的中段引擎，强行做季播剧会导致注水。

---

## 1.3 统一的戏剧底层

不论格式，任何有效叙事都需要：

```text
人物欲望
+ 阻碍
+ 主动策略
+ 失败或代价
+ 状态改变
```

差异在于这些元素的数量、层级和展开速度：

| 格式 | 主目标数量 | 主要人物弧 | 主要反转 | 允许支线 |
|---|---:|---:|---:|---:|
| 概念超短片 | 0–1 | 0–1 个瞬间认知变化 | 1 | 极少 |
| 叙事短片 | 1 | 1 个明确变化 | 1–2 | 通常不需要 |
| 电影 | 1 条主线 | 1 条完整弧，辅线有限 | 3–5 个结构性变化 | 有限且服务主线 |
| 单集剧 | 集级目标 1 个 | 集级变化 + 季级推进 | 1–3 | 可有 B 线 |
| 连续剧 | 季级主线 1 条 | 多人物逐层变化 | 每集局部、季中与季终反转 | 必须受控 |
| 长季剧 | 主线 1–2 条 | 多条弧线并行 | 多层级反转 | 需要季圣经 |

# 2. 启动前决策

## 2.1 格式决策卡

```md
# 格式决策卡

- 项目名称：
- 目标载体：
- 预计时长 / 集数：
- 每集时长：
- 目标受众：
- 观看情境：影院 / 流媒体 / 手机竖屏 / 节展 / 社媒
- 故事核心问题：
- 主角外部目标：
- 主角内部需求：
- 主对抗力量：
- 失败代价：
- 必须保留的体验：
- 可以删去的元素：
- 预算 / 场景 / 角色约束：
- 选择该格式的原因：
- 不选择其他格式的原因：
```

## 2.2 不要错配格式

### 把短片误做成长片

失败信号：

- 核心冲突一句话就能解决；
- 中段只能靠新增角色、事故、秘密拖延；
- 主角没有第二种或第三种策略；
- 结局在 20 分钟已经可预测；
- 大量场景只是在重复同一种情绪。

修复：

- 缩回一个关键时刻；
- 把“人生故事”改为“人生转折”；
- 删除背景解释，用一个可见选择承载主题；
- 若仍希望长片，重新设计多阶段目标和对抗升级。

### 把电影误做成短片

失败信号：

- 需要讲清太多世界规则；
- 主角还没有做出关键选择就结束；
- 结局只像第一幕的触发事件；
- 人物转变没有压力积累；
- 关键关系没有足够场景支撑。

修复：

- 只保留一个冲突和一个关系；
- 将历史背景移除或变成视觉线索；
- 只展示“改变发生的那一天”；
- 或承认它本质是长片/剧集提案，先做 Proof of Concept。

### 把连续故事误做成单元剧

失败信号：

- 每集结束后人物关系和世界状态回到原点；
- 主线谜团没有逐步改变；
- 每集只是换一个“案件/麻烦”；
- 季终局无法汇集前面事件。

修复：

- 为每集设置季级信息或关系状态变化；
- 将单元问题连接到同一对抗系统；
- 让每次解决都制造新的季级代价。

### 把单元剧误做成纯连续剧

失败信号：

- 新观众无法从任一集进入；
- 每集只提供碎片，没有局部满足；
- 观众必须等待很多集才得到一次兑现；
- 中段依赖大量回顾解释。

修复：

- 每集设置可复述的局部问题；
- 每集提供部分答案或情绪兑现；
- 将季级谜团放在集级冲突之下，而不是取代它。

# 3. 概念超短片

## 3.1 定义

概念超短片通常为 1–3 分钟，目标不是讲完一部缩小版电影，而是以一个清楚、可视化、可复述的设问制造强烈体验。

常见用途：

- 社交媒体剧情概念
- AI 视频概念验证
- 品牌或音乐视觉叙事
- 类型片世界观试片
- 导演风格展示
- 长片/剧集的情绪样片

## 3.2 核心问题

```text
如果 X 发生，人物或世界将呈现出怎样不可忽视的后果？
```

概念必须可以通过画面、声音、动作或一个明确选择成立，而不是靠结尾文字解释。

## 3.3 结构

```text
异常建立
→ 人物发现或遭遇
→ 人物作出即时选择
→ 代价 / 反转 / 余味
```

可将时间大致理解为：

| 段落 | 功能 |
|---|---|
| 开始 | 立即建立正常与异常的差异 |
| 中段 | 让人物碰触规则或后果 |
| 结尾 | 给出反转、选择或余味，不解释全部规则 |

## 3.4 创作限制

- 最多一个主要概念。
- 最多一个关键选择。
- 尽量不超过 1–2 个主要角色。
- 尽量不超过 1–2 个地点。
- 不建立复杂世界观百科。
- 不安排完整支线、反派成长线或多重谜题。
- 不用旁白解释画面已经能表达的内容。
- 结尾可以开放，但不能模糊到观众无法理解发生了什么。

## 3.5 对抗审查

检查：

- 关掉声音后，观众能否看懂基本异常？
- 去掉最后一句解释后，概念是否仍成立？
- 如果替换任何角色，情绪是否完全不变？若是，人物功能过弱。
- 结尾是“余味”还是“信息不足”？
- 该片是否只是一则长片预告？若是，应明确定位为概念片，不伪装成完整短片。

# 4. 叙事短片

## 4.1 定义

叙事短片通常为 5–20 分钟。它应完成一次集中、明确、可感知的人物变化，而不是压缩一部长片的全部起承转合。

最稳健的短片结构是：

```text
一个人物
+ 一个关键关系或对抗
+ 一个无法回避的选择
+ 一个改变人物状态的结果
```

## 4.2 适合短片的故事

优先选择：

- 一次坦白、背叛、告别、拒绝、原谅或越界；
- 一个计划在短时间内失控；
- 一个秘密被迫显露；
- 一个角色第一次或最后一次做某件事；
- 一个看似小的行为暴露深层信念；
- 一段关系在有限空间和时间内改变。

不适合直接做短片：

- 需要解释复杂设定才能理解的世界；
- 多年跨度的人生传记；
- 需要多个对手层级的复仇；
- 大量角色共同完成的大型任务；
- 依赖连续谜团、不断揭谜的故事。

## 4.3 短片结构

```text
进入冲突
→ 人物尝试旧策略
→ 阻碍迫使人物改变
→ 关键选择
→ 结果与余波
```

短片不需要硬套三幕页码，但必须有：

- **进入点**：观众尽快理解人物正处于什么不稳定时刻；
- **压力点**：旧策略不起作用；
- **选择点**：人物必须付出代价；
- **结果点**：选择改变人物、关系或观众理解；
- **离开点**：不再解释已经成立的情绪。

## 4.4 短片场景规则

- 场景数量尽量少于长片。
- 每个地点应同时承载多个功能，例如揭示关系、制造阻碍、提供视觉母题。
- 不要安排“介绍人物的场景”与“推动剧情的场景”完全分离。
- 让人物在行动中暴露过去，而不是使用完整回忆段。
- 支线仅在能加压主选择时保留。

## 4.5 短片验收

- [ ] 观众能否说清人物在故事开始时想要什么？
- [ ] 是否只有一个真正的核心冲突？
- [ ] 主角是否亲自做出关键选择？
- [ ] 选择是否有不可逆或情感代价？
- [ ] 结尾是否改变了人物、关系或观众理解？
- [ ] 是否删去所有仅用于解释背景的场景？
- [ ] 是否避免把长片大纲压缩成快节奏摘要？

# 5. 电影长片

## 5.1 定义

电影长片通常为 70–120 分钟。它必须承载一条主角经历多轮主动尝试、失败、学习、代价化选择后完成的完整旅程。

长片的长度不是用于添加角色和事件，而是用于让观众相信：

```text
主角不能轻易改变，
旧方法必须多次失败，
最终选择必须被真正挣得。
```

## 5.2 长片的因果引擎

先写因果脊柱：

```text
旧常态中的缺陷使主角无法处理 A；
A 迫使主角追求 B；
主角用旧方法尝试 B，却导致 C；
C 让代价扩大，迫使主角改变策略；
新的策略揭露 D，使原目标或自我认知崩塌；
在危机中，主角必须在 E 与 F 之间做出价值选择；
这一选择导致结局，并证明或反驳主题。
```

如果中段内容仅是“又发生一件事”，而不是前一选择的后果，长片会松散。

## 5.3 功能结构

不要机械遵从精确页码。使用以下功能节点：

| 节点 | 必须完成的功能 | 常见失败 |
|---|---|---|
| 旧常态 | 展示主角能力、缺陷、欲望和失衡 | 过度铺垫，迟迟不开始 |
| 触发事件 | 令旧策略不再有效 | 事件与主角无关 |
| 第一主动选择 | 主角进入新冲突场，难以回头 | 主角被动被推走 |
| 试探与升级 | 主角尝试、受挫、学习，对手反击 | 一连串无因果事件 |
| 中点 | 信息、目标、权力或风险发生不可逆变化 | 只是更大的打斗或更吵的场面 |
| 压力收紧 | 代价上升，关系与资源被重组 | 重复第一幕冲突 |
| 危机 | 所有简单办法失效，出现价值两难 | 假危机，主角还有轻易解法 |
| 高潮选择 | 主角以变化后的策略行动 | 配角、巧合或外力解决 |
| 余波 | 展示选择代价和新常态 | 解释太多或仓促结束 |

## 5.4 中点的必要性

中点必须改变故事的行动语法，至少满足一项：

- 主角从被动防御变为主动进攻；
- 主角发现目标本身被误解；
- 对手身份、力量或动机被重新定义；
- 原本的盟友关系破裂或翻转；
- 主角得到关键资源，同时失去更重要的东西；
- 成功看似到来，却暴露了更大代价。

如果中点后只是在做更多同类型的场景，说明该片没有第二引擎。

## 5.5 结局原则

结局不是“发生最大的事情”，而是“主角做出最能证明其变化的选择”。

结局必须回答：

- 主角是否实现外部目标？
- 为此付出什么？
- 主角是否改变错误信念？
- 主题被证明、反驳还是复杂化？
- 对手系统如何被改变、绕过或保留？
- 新常态与旧常态有什么可见差异？

## 5.6 长片支线

每条支线必须至少服务以下一项：

- 给主线制造实际障碍；
- 提供主角错误信念的另一种版本；
- 加强主题辩论；
- 迫使主角支付代价；
- 在高潮中影响选择。

若支线只负责增加人物讨喜度、世界观信息或场景数量，删去、合并或改为视觉细节。

## 5.7 长片对抗审查

- 如果删掉中间 20 分钟，主角的策略、关系或认知是否真的不同？若否，中段无效。
- 触发事件是否迫使主角行动，还是仅提供故事背景？
- 主角是否至少三次改变策略，而不只是重复努力？
- 对手是否会根据主角行动调整策略？
- 高潮是否能被开头的主角完成？若能，人物弧未成立。
- 结局是否由巧合、新规则或突然出现的资源解决？
- 主题是否通过选择呈现，而非人物台词宣布？

# 6. 单集电视剧

## 6.1 定义

单集电视剧可指具有相对独立冲突的一集，也可以是连续剧中的一集。无论何种类型，一集应提供局部完成感，同时改变更大故事状态。

单集的核心承诺：

```text
本集提出一个清晰问题，
人物以特定策略应对，
结尾让问题被解决、转化或升级。
```

## 6.2 A/B/C 线

不是每集都需要三条线，但每条线都必须有独立功能。

| 线 | 功能 | 典型长度 |
|---|---|---|
| A 线 | 本集最重要冲突，承载主情绪 | 最多篇幅 |
| B 线 | 反衬主题、推进重要关系或提供平衡 | 中等篇幅 |
| C 线 | 提供轻量人物推进、伏笔或节奏变化 | 最少篇幅 |

规则：

- A 线必须拥有本集的目标、阻碍、转折和结果。
- B 线不能只是“另一组人聊天”；它应折射、加压或反驳 A 线。
- C 线若不能影响人物关系、后续主线或主题，应删除。
- 不要因为格式惯例硬塞 B/C 线。

## 6.3 单集结构

```text
冷开场或快速进入
→ 建立本集问题
→ 人物制定方案
→ 对抗升级
→ 中段改变方案或理解
→ 压力收紧
→ 本集结果
→ Tag / 季级悬念 / 余波
```

冷开场的目的不是“吸睛片段”，而是建立本集要讨论的危险、矛盾、谜团或情绪问题。

## 6.4 单元性与连续性

### 偏单元剧

每集问题大体解决，但人物和世界有累积变化。

适合：

- 职业剧
- 医疗、法律、调查、救援
- 喜剧
- 程序性犯罪剧

关键要求：

- 本集问题必须让主角暴露其长期缺陷或价值观；
- 局部解决不等于回到原点；
- 每集至少推动一项角色或季级关系。

### 强连续剧

每集是同一主线的一段，但仍应有局部目标与兑现。

适合：

- 悬疑
- 家族
- 爱情
- 权谋
- 生存
- 青春群像

关键要求：

- 不让每集沦为“上一集和下一集之间的连接片段”；
- 每集需有可复述的局部变化；
- 每集结尾留下由本集后果产生的问题，而非纯粹中断。

# 7. 连续剧与季播剧

## 7.1 三个层级

连续剧必须同时维护三个层级：

```text
场景级：人物当下想赢什么？
集级：这一集结束时，什么关系/信息/资源改变？
季级：这一季结束时，主角和世界为什么无法回到原点？
```

若只有场景级，故事会碎；
若只有季级，单集会拖；
若只有集级，故事会没有长期牵引。

## 7.2 季级问题

每一季只设一个最重要的季级问题：

```text
主角能否在季终前实现 X，
并承担 Y 的代价？
```

示例：

```text
一名被停职的城市照明设计师能否在季终前证明预测犯罪系统伪造数据，
并在不牺牲妹妹的情况下公开证据？
```

季级问题需要：

- 可被清晰回答；
- 不能在第二集轻易结束；
- 可通过多阶段策略推进；
- 能承载多人物关系；
- 季终必须因人物选择而产生答案。

## 7.3 集级发动机

每集至少推进季级问题的一种方式：

- 获得或失去线索；
- 改变结盟关系；
- 暴露一个秘密；
- 完成或失败一个计划；
- 提高时间、身份、关系或资源代价；
- 迫使人物跨越或守住底线；
- 重新解释之前事件；
- 让对手更接近胜利。

不要用“新麻烦出现”替代推进。新麻烦必须从既有选择、世界规则或对手策略中产生。

## 7.4 季结构

一个稳健季结构可按功能理解：

| 季段 | 主要功能 | 核心问题 |
|---|---|---|
| 季初 | 建立世界、主问题、人物关系和初始策略 | 为什么现在必须行动？ |
| 早季 | 主角试探规则，第一次失败或小胜 | 旧策略为何不够？ |
| 季中 | 真相/目标/阵营发生重大翻转 | 我们之前理解错了什么？ |
| 后季 | 对手反击，代价与关系压力全面上升 | 主角还剩什么办法？ |
| 季终前 | 危机，最简单方案全部失效 | 主角真正愿意牺牲什么？ |
| 季终 | 主角做出季级选择，解决或复杂化季级问题 | 什么永远改变了？ |

## 7.5 季终局

季终局不应只是：

- 新反派突然出现；
- 主角遭遇车祸；
- 一通电话带来新消息；
- 已解决的谜团被临时推翻；
- 角色失忆；
- “其实一切都是梦”。

好的季终局应完成三件事：

1. 回答本季核心问题；
2. 兑现关键人物弧与主题；
3. 由结局自然产生下一季的新问题。

```text
本季主角赢得了什么？
为此失去了什么？
这一胜利为何让下一季的冲突更复杂？
```

# 8. 人物容量与关系网络

## 8.1 人物数量不是卖点

角色越多，观众理解、剧本维护和制作成本越高。

新增人物必须至少满足一个条件：

- 提供主角无法从现有角色获得的阻力；
- 代表主题的不同答案；
- 改变重要关系网络；
- 掌握不可替代的资源或信息；
- 在高潮中造成独特后果。

否则，合并到现有角色。

## 8.2 格式与角色容量

以下只是风险提示，而非硬上限：

| 格式 | 建议聚焦人数 | 风险 |
|---|---:|---|
| 概念超短片 | 1–2 名主要人物 | 新角色会稀释概念 |
| 叙事短片 | 1–3 名核心人物 | 支线会吞掉关键选择 |
| 电影 | 1 名主角 + 有限关键配角 | 群像会挤压主角弧 |
| 单集剧 | 视 A/B 线配置 | 线索难以回收 |
| 季播剧 | 核心群像可更多，但需分层 | 每人都没有弧线 |

## 8.3 关系是动态系统

关系线必须记录状态变化：

```md
| 人物 A | 人物 B | 初始关系 | 共同利益 | 隐藏冲突 | 当前权力 | 关键转折 | 季终状态 |
```

不要将“他们是朋友”“他们是恋人”“他们是敌人”当成关系设计。关系的戏剧价值来自信息、权力、目标和底线的变化。

# 9. 场景密度与信息分配

## 9.1 场景必须有功能

每个场景至少完成一项：

- 推进目标；
- 增加或改变阻碍；
- 改变关系权力；
- 释放、误导或重构信息；
- 迫使人物选择；
- 为后续高潮建立必要因果；
- 以视觉或行动呈现主题。

若一个场景只完成“让观众知道一个背景事实”，优先把该事实并入冲突场景。

## 9.2 信息不是越晚越好

悬念来自观众知道“有问题且后果重大”，不是完全不知道发生什么。

区分：

| 机制 | 观众知道什么 | 体验 |
|---|---|---|
| 好奇 | 知道存在缺口 | 想知道真相 |
| 悬念 | 知道危险及其可能后果 | 担心人物如何应对 |
| 惊奇 | 与人物同时得知反转 | 瞬间冲击 |
| 困惑 | 不知道人物、目标和规则 | 容易退出 |

不要把困惑误当成高级悬疑。

## 9.3 闪回与非线性

仅当非线性结构能实现线性叙事做不到的功能时使用：

- 让观众重新理解当前选择；
- 制造信息差；
- 对照人物旧信念与新行为；
- 延迟但不隐藏必要因果；
- 改变道德判断。

每段闪回必须回答：

```text
它改变了观众对当下哪一个行动、人物或风险的理解？
```

若答案是“为了讲背景”，优先改为当前冲突中的信息泄露。

# 10. 可拍性与制作思维

## 10.1 写作不是无视制作

即使项目仍在开发，也应识别叙事价值与制作代价。

每个重大场景标注：

```md
- 场景功能：
- 必须呈现的情绪结果：
- 叙事不可替代元素：
- 制作成本来源：
- 可降级方案：
```

## 10.2 保留因果，降低表面成本

当预算或 AI 视频能力有限时，按以下顺序处理：

1. 先保留人物选择；
2. 保留选择的可见后果；
3. 用反应、声音、局部细节或场外事件代替昂贵展示；
4. 合并场景、角色和时间；
5. 最后才删改主要事件。

禁止因为制作难度而让高潮变成没有选择的旁白说明。

## 10.3 长片与剧集的资产控制

- 长片：避免中段不断新增只出现一次的地点、角色与道具。
- 剧集：建立常驻场景和可反复加压的关系空间。
- 连续剧：每集新增资产须服务季级升级，不能只为视觉换新。
- AI 视频：角色服装、伤痕、道具位置、时段和天气必须进入连续性表。

# 11. 格式专用对抗式审查

## 11.1 概念超短片审查

- 这个概念是否能在一句话内复述？
- 是否需要大量解释才能成立？
- 画面是否承担了概念，而不是台词？
- 最后 10 秒带来的是清晰余味，还是信息缺失？
- 是否存在可以删除而完全不影响体验的镜头？

## 11.2 叙事短片审查

- 主角是否在一个关键时刻被迫选择？
- 是否存在第二个故事、第二个主题或第二条人物弧在抢占篇幅？
- 如果删去背景设定，核心情绪是否仍成立？
- 结局是选择的后果，还是突然的反转？
- 是否可以从更晚的时点开始，并更早结束？

## 11.3 长片审查

- 触发事件是否真正迫使主角改变行动？
- 主角是否反复调整策略，而非反复遭受同类事件？
- 中点是否改变目标、风险、认知或权力结构？
- 危机是否消除了轻易选项？
- 高潮是否由主角以改变后的选择实现？
- 是否存在可删去 10–20 分钟而主线不变的中段？
- 所有支线是否在加压主线或主题？

## 11.4 单集剧审查

- 本集 A 线的问题是否可清晰复述？
- A 线是否拥有目标、阻碍、转折与局部结果？
- B/C 线是否真正反衬或推进主题？
- 本集是否既有局部满足，又改变季级状态？
- Tag 是否制造后续影响，而不是硬留悬念？

## 11.5 连续剧/季播剧审查

- 每一集是否提供局部目标、变化和兑现？
- 季级问题是否只有一个清晰核心？
- 季中是否发生不可逆重构？
- 对手和系统是否依据主角行动不断适应？
- 季终是否回答了季级问题？
- 下一季问题是否来自季终后果？
- 是否出现为延长集数而让人物不沟通、不行动或突然失智？

# 13. 最终放行门禁

## 所有格式

- [ ] 格式选择服务故事，而不是市场标签或作者偏好
- [ ] 主角、目标、阻碍、代价可被一句话说明
- [ ] 核心事件具有因果关系
- [ ] 主角在关键节点主动选择
- [ ] 结局由前文选择导致
- [ ] 人物、时间、信息、世界规则连续
- [ ] 可拍性和制作约束已标注
- [ ] 已执行对应格式的对抗式审查
- [ ] P0 问题已修复或被明确接受

## 概念超短片

- [ ] 只有一个清晰概念
- [ ] 可视化而非依赖解释
- [ ] 结尾留下明确余味

## 叙事短片

- [ ] 只有一个核心人物选择
- [ ] 没有被压缩的长片支线
- [ ] 情绪结果已被挣得

## 电影长片

- [ ] 中点改变故事行动语法
- [ ] 主角至少多次调整策略
- [ ] 危机是真实两难
- [ ] 高潮证明人物变化

## 剧集与季播剧

- [ ] 每集有局部问题与状态变化
- [ ] 每季有一个明确核心问题
- [ ] 季中有重大重构
- [ ] 季终回答本季问题并产生后果
- [ ] 没有通过人物失智或随机事故拖延主线

# 14. 与主 Skill 的协作

加载本文件时：

1. 先遵循主 `SKILL.md` 的状态机与阶段门。
2. 先依据故事需要确定格式，再读取对应章节；不得一次套用所有格式模板。
3. 微短剧规则由 `short-drama-playbook.md` 管理，不在本文件重复。
4. 剧本排版、Fountain、中文/英文场景标题和导出规则由 `screenplay-format-cn-en.md` 管理。
5. 规则冲突统一按
   `governance/control-plane-contract.md#71-规则冲突优先级`处理；本文件属于“当前任务明确路由到的领域 reference”层。

6. 不得以“类型惯例”“格式限制”或“时长不够”为理由跳过因果、人物动机、选择代价和连续性审查。
