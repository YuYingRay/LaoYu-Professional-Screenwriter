# 1. 第一性原理

## 1.1 钩子不是中断

无效定义：

```text
在一句话说完前切黑。
在门打开前切黑。
电话响起时切黑。
突然有人晕倒。
```

这只是中断。

有效钩子是一个已经发生的因果变化，迫使观众必须知道后果：

```text
人物做出选择或遭遇反转
→ 权力、关系、信息、资源或风险发生变化
→ 变化产生无法忽略的未结问题
→ 下一集能够合理承接并兑现
```

因此：

```text
中断 ≠ 钩子
惊吓 ≠ 悬念
信息隐藏 ≠ 好奇
拖延 ≠ 追更
```

---

## 1.2 付费点不是收费闸门

付费点的真正价值不是“把观众挡在门外”，而是：

```text
观众已理解核心问题
+ 已投入人物或结果
+ 即将迎来高价值兑现
+ 结果仍不确定
+ 下一集会迅速、可信地给出回报
```

如果观众还不知道自己为什么要关心，或在付费后发现只是继续拖延，付费点会损害信任和长期留存。

核心原则：

```text
用期待促成解锁，
用兑现换取信任，
用新的因果问题推动下一次追更。
```

---

## 1.3 注意力循环

单集微短剧的最小注意力循环：

```text
Hook
→ Question
→ Goal
→ Resistance
→ Reversal
→ Consequence
→ Next Question
```

中文解释：

```text
钩住注意
→ 建立问题
→ 明确人物目标
→ 设置阻力
→ 发生反转
→ 展示后果
→ 产生下一集问题
```

如果某一集只完成“Hook → Question”，却没有行动、反转或后果，它只是预告，不是剧情。

# 2. 三层钩子系统

短剧需要同时维护三种层级的钩子。

| 层级 | 出现位置 | 目的 | 观众问题 |
|---|---|---|---|
| 入口钩子 | 前 1–15 秒 | 阻止划走 | “发生了什么？” |
| 过程钩子 | 集中段 | 阻止中途退出 | “他/她会怎么做？” |
| 结尾钩子 | 最后 5–15 秒 | 推动下一集 | “接下来会怎样？” |

只设计集尾钩子、忽略开场和中段，常导致观众在到达结尾前就退出。

# 3. 入口钩子

## 3.1 入口钩子的任务

入口钩子必须快速提供至少两项：

- 人物
- 失衡
- 欲望
- 威胁
- 时间限制
- 关系冲突
- 秘密
- 高价值资源
- 异常规则

推荐结构：

```text
人物 + 立即失衡 + 具体风险
```

示例：

```text
林夏刚打开城市照明后台，就看到妹妹的名字被标记为“高风险目标”。
```

这句话同时提供人物、异常、关系、威胁和问题。

## 3.2 入口钩子类型

### A. 即时损失

```text
主角正在失去身份、关系、工作、自由、金钱、证据或安全。
```

示例：

```text
婚礼现场，女主被当众指控伪造怀孕证明。
```

### B. 不可能任务

```text
主角必须在极短时间内完成看似无法完成的任务。
```

示例：

```text
午夜前，她必须让系统撤销对父亲的死亡判定。
```

### C. 权力错位

```text
观众看到弱势者拥有隐藏资源，或强势者突然失去控制。
```

示例：

```text
被赶出公司的实习生，收到董事会投票系统的管理员密钥。
```

### D. 禁忌信息

```text
主角得知一个不能知道的真相。
```

示例：

```text
女主在失踪人口数据库里看见自己明天的照片。
```

### E. 关系破裂

```text
最重要的关系在第一时间出现无法回避的裂缝。
```

示例：

```text
父亲在病床前承认：他救回的不是她，而是她的替身。
```

### F. 规则异常

```text
日常规则突然失效，人物被迫立即应对。
```

示例：

```text
整座城市的灯每熄灭一次，就有一个人的身份记录被删除。
```

## 3.3 入口钩子反审查

拒绝以下错误：

| 错误 | 为什么会失败 | 修复 |
|---|---|---|
| 先讲背景再给冲突 | 观众尚未获得投入理由 | 从失衡或后果开始 |
| 旁白解释设定 | 用语言替代体验 | 用动作、物件、冲突展示 |
| 只有视觉奇观 | 不知道人物为何在乎 | 增加人物目标与代价 |
| 虚假危险 | 很快证明只是梦、误会或恶作剧 | 让风险具有真实后果 |
| 只写“震惊” | 情绪没有对象 | 明确谁失去什么、何时失去 |
| 开场人物过多 | 观众无法定位主角 | 先锁定一个 POV 人物 |

# 4. 过程钩子

## 4.1 过程钩子的任务

过程钩子存在于单集 25%–80% 的位置，目的是让观众不在中途退出。

常见形式：

```text
计划出现缺口
→ 对手先一步行动
→ 盟友隐瞒信息
→ 资源即将失效
→ 人物发现自己判断错误
→ 关系从合作变为对抗
```

## 4.2 中段推进规则

每 20–40 秒或每一个明显段落，至少发生一项变化：

- 新信息
- 新阻碍
- 新策略
- 权力变动
- 关系转向
- 时间压力增加
- 代价升级
- 目标改写

这不是要求每 20 秒强行反转，而是避免持续解释、重复争吵或无结果走动。

## 4.3 过程钩子示例

```text
主角拿到证据
→ 发现证据的上传记录显示：提交人是她自己
```

```text
主角同意合作
→ 合同条款要求她先交出唯一的监护权
```

```text
主角成功逃出大楼
→ 手机收到门禁记录：她从未离开过大楼
```

# 5. 结尾钩子

## 5.1 强钩子的五个条件

一个集尾钩子至少满足其中三项，最好满足四项：

1. **因果性**：来自本集人物的行动、选择或既有规则。
2. **变化性**：改变权力、信息、目标、关系、资源或风险。
3. **明确性**：观众知道下一集要看什么。
4. **不确定性**：结果不能被轻易猜透。
5. **可兑现性**：下一集能在合理时间内开始回答。

公式：

```text
本集选择 / 反转
+ 不可忽略的后果
+ 明确未结问题
= 有效结尾钩子
```

## 5.2 钩子类型库

### 1. 不可逆选择

人物做出无法撤回的行动。

```text
主角当众签下离婚协议，却在最后一页写下对方最害怕公开的名字。
```

### 2. 关系翻转

人物关系、忠诚或权力改变。

```text
女主终于选择相信男主，男主却收到命令：今晚必须把她交出去。
```

### 3. 真相重构

新信息改变前文意义。

```text
DNA 报告证明孩子不是他的，但报告日期早于两人相识。
```

### 4. 资源转移

关键资源被夺走、失效或易主。

```text
主角刚拿到唯一备份，系统提示：文件将在九十秒后公开发送给全城。
```

### 5. 迫近威胁

危险已经启动，且具有明确目标与时限。

```text
城市的红灯开始逐街熄灭。下一条街，就是主角妹妹所在的学校。
```

### 6. 计划反噬

主角策略成功一半，但暴露了更大问题。

```text
主角用直播逼对手承认造假，却让对手确认了她掌握的证据来源。
```

### 7. 道德两难

人物必须在两个都要付代价的选项中选择。

```text
救父亲，就必须交出会让姐姐入狱的录音。
```

### 8. 身份或视角翻转

慎用。必须有前文线索，并改变当前行动。

```text
追捕主角的警官打开档案，档案照片是他年轻时的自己。
```

## 5.3 弱钩子禁止清单

以下默认视为弱钩子，除非前文已经建立具体因果：

```text
有人敲门
手机响起
角色突然晕倒
角色突然被车撞
“你居然是……”
一个黑衣人出现
角色醒来发现是梦
镜头停在震惊表情
一句“未完待续”
```

修复方式不是“让它更大声”，而是补足：

```text
前因
→ 人物选择
→ 状态变化
→ 具体后果
```

# 6. 钩子兑现

## 6.1 信任经济

观众点击下一集，是对作者的临时信任。

下一集必须尽快兑现前集承诺中的至少一部分：

```text
钩子提出的问题
→ 立即承接
→ 提供答案、反答案或更深答案
→ 由答案产生新行动
```

不要连续多集采用：

```text
钩子：马上揭晓身份
→ 下一集：回忆五分钟前
→ 再下一集：其他角色误会
→ 再下一集：身份仍未揭晓
```

这会将悬念转化为欺骗感。

## 6.2 兑现时间

建议将钩子兑现分为：

| 类别 | 建议兑现位置 | 适用情境 |
|---|---|---|
| 小钩子 | 下一集开头 5–20 秒 | 局部行动或信息 |
| 中钩子 | 下一集前 1/3 | 关系转折、局部秘密 |
| 大钩子 | 1–3 集内逐层兑现 | 主线谜团、终局资源 |
| 季级钩子 | 本季内明确回收 | 季终问题、长期秘密 |

重要：可以延迟**完整答案**，但不能延迟**初步回报**。

## 6.3 三层兑现

一个好的大钩子可分三层：

```text
第一层：立刻确认问题是真的
第二层：揭示初步后果
第三层：提供真正答案或更深反转
```

示例：

```text
钩子：主角发现妹妹被系统标为“高风险目标”。

下一集开头：确认名单真实，且无法删除。
下一段：妹妹收到异常工作邀请。
两集后：发现“高风险”标签是清除异议者的预处理机制。
```

这不是拖延，因为每层都改变行动与风险。

# 7. 付费点设计

## 7.1 付费点的最低前提

设置付费点前，必须确认：

- 观众已经认识并关心至少一个核心人物；
- 主线问题已经清楚；
- 观众理解当前风险；
- 即将发生的事件具有高情绪或高信息价值；
- 下一集可以快速提供回报；
- 后续还有足够的新因果链，而不是只剩一个答案。

若不满足，优先继续免费建立信任，而不是提前收费。

## 7.2 付费点的四种价值

| 类型 | 观众愿意解锁的原因 | 适合节点 |
|---|---|---|
| 答案价值 | 即将知道关键真相 | 身份、秘密、证据揭晓 |
| 情绪价值 | 即将得到关系或正义兑现 | 告白、决裂、复仇、和解 |
| 行动价值 | 即将看到不可逆行动结果 | 签约、公开、救援、出逃 |
| 风险价值 | 即将确认重大损失或存活 | 倒计时、追捕、资源失效 |

强付费点通常同时包含两种价值，例如：

```text
身份真相 + 关系决裂
```

或：

```text
不可逆行动 + 迫近风险
```

## 7.3 付费点位置

付费点的位置必须由故事成熟度决定，而不是机械设定“第 N 集”。

检查顺序：

```text
观众是否理解故事？
→ 是否建立人物投入？
→ 是否见过至少一次可信兑现？
→ 主线是否已出现高价值问题？
→ 此刻是否存在不可逆后果？
```

只有全部为“是”，才考虑放置。

不要把免费集全部写成铺垫、把付费后才写成真正剧情。免费阶段同样必须提供完整的小型因果循环与局部兑现。

## 7.4 付费点模板

```md
# 付费点设计卡

- 付费点编号：
- 所在集数：
- 当前主线问题：
- 当前人物投入：
- 观众已知：
- 观众尚不知但已期待：
- 即将兑现的价值：
- 钩子类型：
- 下一集 20 秒内的初步回报：
- 1–3 集内的完整回报：
- 回报后产生的新问题：
- 若观众不解锁，是否仍能理解此前剧情：
- 是否存在“强行截断”风险：
```

# 8. 付费后的承诺管理

## 8.1 解锁后第一集

付费后的第一集承担最高信任压力。

必须做到：

1. 立即承接付费前钩子；
2. 在前 20 秒提供真实新信息、真实行动或真实后果；
3. 不能只回顾、拖延、切换无关支线；
4. 不能用“其实是误会/梦/恶作剧”取消前集风险；
5. 在兑现后建立下一条更高价值因果链。

## 8.2 三集回报窗口

若付费点承诺的是大问题，建议采用：

| 集数 | 任务 |
|---|---|
| 解锁后第 1 集 | 确认问题真实，给初步回报 |
| 解锁后第 2 集 | 展示人物行动与代价 |
| 解锁后第 3 集 | 给出核心答案、关键转折或情绪兑现 |

如果三集后仍只是在重复“快揭晓了”，应视为重大信任风险。

## 8.3 不得取消的承诺

以下情况下，除非作品明确是喜剧或元叙事，否则不要在付费后取消承诺：

- 刚才的一切是梦；
- 关键证据是伪造且没有新故事价值；
- 已死亡人物其实根本没死，但没有前文线索；
- 关系告白被临时打断，随后数集不再提；
- 高风险事件实际毫无后果；
- 钩子中的人物、物品或事件与主线无关。

反转允许改变答案；不允许撤销观众已经投入的情绪。

# 9. 追更循环

## 9.1 追更不等于无限延长

持续观看来自：

```text
解决一个问题
→ 结果改变人物处境
→ 新处境产生更高层问题
→ 人物必须采取新策略
```

不是：

```text
重复同一种危机
→ 再次切黑
→ 再次延迟答案
```

## 9.2 问题阶梯

设计全剧时，建立问题阶梯：

```md
| 层级 | 问题 | 何时提出 | 何时部分兑现 | 何时完整兑现 | 兑现后的新问题 |
|---|---|---|---|---|---|
| 集级 | 本集能否拿到证据？ | 本集前段 | 本集末 | 下集开头 | 证据是谁留下的？ |
| 段落级 | 谁在操控系统？ | 第 1-3 集 | 第 6 集 | 第 12 集 | 系统为何选择主角家人？ |
| 季级 | 主角能否阻止系统清除妹妹？ | 第 1 集 | 中季 | 季终 | 主角公开真相的代价是什么？ |
```

规则：

- 每个大问题必须有小问题持续供给行动。
- 每个小问题的答案应让大问题更具体、更危险或更复杂。
- 不要同时抛出过多未解问题；观众必须知道哪个最重要。
- 不要将同一答案拆成太多无变化的小集。

## 9.3 情绪波形

持续追更需要交替：

```text
压力
→ 局部释放
→ 更高压力
→ 关系缓冲或角色深化
→ 重大反转
→ 代价
→ 新策略
```

禁止连续十集只让主角被羞辱、误会、追捕或失败。

没有局部胜利，观众会疲劳；
没有新代价，胜利会无意义。

# 10. 钩子与人物

## 10.1 钩子必须暴露选择

低级钩子常依赖外部事件：

```text
有人突然出现。
有人突然来电。
突然发生事故。
```

高级钩子把人物选择推到不可逆边缘：

```text
主角选择公开证据，
却因此把唯一盟友推入危险。
```

人物选择型钩子的优点：

- 更符合因果；
- 更能推动人物弧；
- 更难被替代；
- 更有情绪代价；
- 更容易在下一集兑现。

## 10.2 主角主动性检查

每 3–5 集检查：

- 主角是否在主动创造钩子，还是只被钩子砸中？
- 主角是否根据失败调整策略？
- 主角是否承担了自己的选择后果？
- 主要转折是否源于人物关系和目标？
- 如果将主角替换成任意角色，故事是否基本不变？

若主角只负责被救、被认亲、被告知真相或等待反派犯错，必须重构。

# 11. 钩子与信息管理

## 11.1 观众、人物与对手的知识

维护知识矩阵：

```md
| 信息 | 观众知道 | 主角知道 | 对手知道 | 盟友知道 | 何时改变 | 戏剧用途 |
```

钩子通常来自知识差，但知识差必须清楚。

| 情况 | 体验 | 适合用途 |
|---|---|---|
| 观众知道，主角不知道 | 悬念 | 危险逼近、背叛、陷阱 |
| 主角知道，观众不知道 | 好奇 | 调查、策略、秘密 |
| 对手知道，双方不知道 | 谜团 | 后台操控、隐藏规则 |
| 观众与主角同时得知 | 惊奇 | 重大反转、身份揭示 |

不要同时让所有人都不知道发生什么，然后称之为悬念。

## 11.2 信息释放的公平性

重大反转至少满足之一：

- 前文有可回看的线索；
- 反转来自已建立的角色动机；
- 反转来自已建立的世界规则；
- 反转揭示的是信息，而非临时新增规则；
- 反转迫使人物改变行动。

不公平反转：

```text
最后一刻突然出现从未提及的双胞胎。
主角突然拥有从未展示的技能。
系统突然具备此前从未暗示的新能力。
关键证人恰好路过并解决主线。
```

# 12. A/B 测试与创作实验

## 12.1 可测试与不可测试

可以测试：

- 首集不同开场顺序；
- 同一故事的不同入口钩子；
- 集尾钩子的具体表达；
- 标题、封面、简介与首集第一画面；
- 信息揭示的早晚；
- 同一反转的更清晰或更直接版本。

不应只依数据机械测试：

- 主题是否值得表达；
- 人物是否具有尊严；
- 是否应美化伤害、操控或歧视；
- 是否将作品无限拉长；
- 是否用欺骗式钩子伤害长期信任。

## 12.2 假设驱动测试

建立实验卡：

```md
# 钩子实验卡

- 目标：
- 当前版本：
- 替代版本：
- 唯一变化变量：
- 预期影响：
- 主要指标：
- 次要指标：
- 样本/渠道：
- 结果：
- 结论：
- 是否保留：
- 是否引入新的叙事风险：
```

一次只改变一个关键变量。若同时改了开场人物、台词、音乐、剪辑和结尾，无法知道什么导致变化。

## 12.3 数据解释防错

不要仅凭某一集点击高就断言“这个套路有效”。

检查：

- 流量来源是否相同？
- 标题、封面和投放是否改变？
- 前集是否为该集积累了期待？
- 高点击后是否有高完成和持续追更？
- 付费后是否出现明显流失？
- 是否只吸引了猎奇点击，却伤害长期品牌？

指标必须与剧情因果共同解释。

# 13. 商业与伦理边界

## 13.1 不把成瘾当作唯一目标

短剧可以设计追更，但不应依赖：

- 虚假危险；
- 永不兑现；
- 无尽重复；
- 误导性标题或封面；
- 对痛苦、性别、贫困、疾病或暴力的剥削；
- 以羞辱弱势人物作为唯一爽点；
- 付费后继续人为阻断已承诺的答案。

商业化目标必须服从长期叙事信任。

## 13.2 付费透明性

剧本侧应准备：

```md
- 免费内容范围：
- 候选付费点：
- 付费后首集承诺：
- 关键答案预计兑现区间：
- 不可取消的剧情承诺：
- 内容风险提示：
```

产品端的价格、退款、订阅、广告和未成年人保护规则，必须由平台、法务与产品团队依据目标市场最新规定制定；剧本 Skill 不编造法律结论。

# 14. 对抗式审查

## 14.1 观众红队

假设观众随时准备退出：

- 前 5 秒我看到了什么具体失衡？
- 前 15 秒我知道谁在乎什么吗？
- 这集的核心问题是什么？
- 我在中段为什么没有划走？
- 结尾的问题是否明确？
- 下一集是否值得立刻点开？
- 我是否已经被同类反转欺骗过太多次？

## 14.2 逻辑红队

- 钩子是否由人物行动或已知规则产生？
- 下一集是否真正承接？
- 延迟是否具有故事理由？
- 反转是否有前文线索？
- 人物为什么不直接沟通、查证、离开、求助或采取更合理行动？
- 对手是否会采取更有效反制？
- 付费点前后是否存在逻辑断裂？

## 14.3 人物红队

- 主角是否在主动制造变化？
- 钩子是否迫使主角选择？
- 主角是否因自己的选择付出代价？
- 人物是否只是在重复“震惊、哭泣、求饶、误会”？
- 关系变化是否有实际行动支撑？
- 反派是否有策略，而非只会突然出现？

## 14.4 信任红队

- 钩子是否承诺了下一集不会兑现的内容？
- 是否把答案拖过合理期限？
- 付费后首集是否只是在回顾和拖延？
- 是否用梦、误会、失忆、巧合取消前集风险？
- 是否为了延长集数让人物突然失智？
- 观众看完后会觉得“被吊住”，还是“被耍了”？

## 14.5 商业红队

- 免费阶段是否已经展示作品真正的叙事价值？
- 付费点是否设置在高价值因果节点？
- 付费后的三集是否都有回报？
- 是否把所有兑现都集中在最后，造成中段疲劳？
- 是否存在“集数更多但每集更空”的风险？
- 缩短季数、合并重复事件后，留存和口碑是否可能更好？

# 15. 评分与放行

## 15.1 钩子评分卡

对每个入口、过程或结尾钩子按 0–5 分评分：

| 维度 | 问题 |
|---|---|
| 清晰 | 观众是否迅速知道发生什么？ |
| 关系 | 是否涉及观众已经关心的人或资源？ |
| 因果 | 是否来自前文行为、选择或规则？ |
| 变化 | 是否改变目标、风险、信息、权力或关系？ |
| 不确定 | 是否存在多个合理结果？ |
| 可兑现 | 是否能在合理时间内回报？ |
| 独特 | 是否可被任意俗套替换？ |
| 人物性 | 是否迫使人物做选择？ |

评分解释：

```text
0–1：无效或欺骗性中断
2：存在问题，但缺乏明确后果
3：可用，但需要增强人物/因果
4：强钩子，可推动下一集
5：强烈、清晰、因果充分，并改变主线
```

## 15.2 付费点评分卡

| 维度 | 问题 |
|---|---|
| 人物投入 | 观众是否已经关心至少一个人？ |
| 问题清晰 | 观众是否明确知道即将兑现什么？ |
| 情绪价值 | 是否具有关系、正义、恐惧、希望或身份价值？ |
| 信息价值 | 是否接近关键答案？ |
| 不可逆性 | 是否涉及真正会改变故事的后果？ |
| 兑现计划 | 下一集 20 秒与三集内是否有回报？ |
| 新引擎 | 回报后是否产生新的因果问题？ |
| 信任风险 | 是否像人为收费截断？ |

只有在“人物投入、问题清晰、兑现计划”三项都达到高分时，才建议作为实际付费点。

## 15.3 最终放行门禁

- [ ] 首集前 15 秒存在具体人物、失衡和风险
- [ ] 每集都有目标、阻碍、变化和未结后果
- [ ] 入口、过程和结尾三层钩子均已设计
- [ ] 钩子来自因果，不是随机中断
- [ ] 下一集会在合理时间兑现上一集承诺
- [ ] 每个付费点都有人物投入、清晰问题和回报计划
- [ ] 免费内容本身提供真实剧情价值
- [ ] 付费后首集在前 20 秒提供真实回报
- [ ] 三集内不存在纯拖延式“继续吊胃口”
- [ ] 不靠梦、误会、失忆、巧合取消已建立风险
- [ ] 主角通过选择而非被动遭遇推动主要钩子
- [ ] 连续追更来自问题升级，不是重复羞辱或重复反转
- [ ] 已执行观众、逻辑、人物、信任和商业五类红队审查
- [ ] 所有 P0 信任问题已修复或被明确接受

7. 禁止将“优化留存”解释为允许欺骗观众、拖延兑现、剥削敏感内容或牺牲人物逻辑。
