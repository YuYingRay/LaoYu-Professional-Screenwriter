# 1. 适用边界

## 适用任务

使用本手册的典型项目：

- 中文竖屏短剧
- 海外短剧平台的连续剧情内容
- 单集 45 秒至 3 分钟的连续剧
- 20–100 集的强情节连续故事
- AI 视频批量生成的短剧项目
- 需要高频反转、悬念和追更动力的内容

## 不适用任务

不要把本手册作为以下内容的默认规则：

- 90–120 分钟电影
- 强作者表达的艺术片
- 以氛围、观察或散文性叙事为主的作品
- 纪录片
- 纯喜剧段子
- 教学视频
- 广告脚本
- 单一独立短片

若用户未说明载体，先判断其时长、平台和观看方式。不能因为“短”就自动套用微短剧的高频狗血、集尾断裂或付费点逻辑。

# 2. 微短剧的第一性原理

微短剧的竞争对象不是其他影视剧，而是用户手指的下一次滑动。

因此，短剧不是把长剧压缩，而是重新设计注意力循环：

```text
快速理解
→ 产生未结问题
→ 人物主动争取
→ 阻碍或反转
→ 新代价
→ 强制观众进入下一集
```

每一集应在有限时长内完成一个最小戏剧循环：

```text
局部目标 + 即时阻碍 + 策略碰撞 + 权力/信息反转 + 未完成后果
```

如果一集只做背景交代、回忆前情、人物闲聊或重复情绪，它通常不应单独存在。

---

# 3. 核心指标

不要机械追逐数据，但要将以下体验变量视为结构质量的代理指标。

| 指标 | 观众体验问题 | 编剧变量 |
|---|---|---|
| 首集留存 | 为什么我不划走？ | 失衡、威胁、欲望、秘密、身份差 |
| 单集完播 | 这集为什么要看完？ | 目标清晰、冲突升级、信息变化 |
| 下一集点击 | 我为什么必须继续？ | 未结后果、不可逆行动、关系反转 |
| 连续追更 | 为什么不是只看一集？ | 主线谜团、递增代价、人物关系演变 |
| 付费转化 | 为什么此刻值得付费？ | 已铺垫问题即将兑现，但结果不可预测 |
| 口碑/分享 | 我为什么愿意复述？ | 高概念、情绪释放、反转合理、人物选择 |

警告：

- 高冲突不等于高噪音。
- 高反转不等于随机反转。
- 高爽感不等于无代价羞辱或无逻辑碾压。
- 高付费欲不等于在所有结尾都硬切黑。
- 短剧节奏快，不等于人物和因果可以失真。

# 4. 项目启动

## 4.1 立项输入

开始前明确以下内容：

```md
# 短剧立项卡

- 项目名（暂定）：
- 目标市场：国内 / 北美 / 拉美 / 东南亚 / 其他
- 输出语言：
- 平台与观看场景：
- 总集数：
- 单集时长：
- 目标受众：
- 类型组合：
- 情绪承诺：
- 主角：
- 主角的具体目标：
- 主要阻碍：
- 失败代价：
- 核心秘密或谜团：
- 结局类型：
- 内容边界：
- 制作约束：
- AI 生成约束：
```

## 4.2 最短 Logline

用一句话写清：

```text
当【突发失衡】迫使【有缺陷的主角】去【具体目标】时，
主角必须战胜【会主动反击的阻碍】，
否则【将在短期内失去的具体事物】。
```

合格示例：

```text
当被陷害入狱的灯光设计师发现整座智慧城市正在利用夜景照明筛选“高风险市民”时，
他必须在七天内找出幕后算法的训练证据，
否则妹妹将成为系统的下一名“意外事故”受害者。
```

不合格示例：

```text
一个普通女孩经历成长和爱情。
```

问题：没有触发事件、目标、阻碍、代价和独特冲突。

## 4.3 类型组合

短剧可以组合类型，但只能有一个主情绪承诺。

常用组合：

| 主类型 | 可组合元素 | 主要承诺 |
|---|---|---|
| 逆袭 | 身份、职场、复仇、豪门 | 从被压制到夺回权力 |
| 爱情 | 契约、误会、救赎、身份差 | 关系靠近与真相阻碍 |
| 悬疑 | 复仇、犯罪、家族、科技 | 真相逐层反转 |
| 都市 | 职场、家庭、情感、阶层 | 现实压力中的选择 |
| 奇幻 | 重生、穿越、系统、超能力 | 新规则带来的权力重排 |
| 家庭 | 亲情、秘密、继承、伦理 | 关系修复或决裂 |
| 轻喜剧 | 恋爱、职场、误会、反差 | 高密度反差与情绪释放 |
| 科幻 | AI、算法、时间、身份 | 规则危机与人性选择 |

不要将“霸总、萌宝、战神、重生、狼人”等标签直接视为故事。它们只是高效类型外壳，仍需回答：谁要什么、谁反对、失败会怎样、人物会如何改变。

# 5. 首集设计

## 5.1 首集使命

首集不是解释世界观，而是向观众证明：

1. 这里有一个值得观看的失衡。
2. 主角无法用旧方式解决它。
3. 继续观看能够获得情绪或答案。
4. 该故事拥有独特的冲突引擎。

## 5.2 前 15 秒规则

单集开头尽快呈现下列至少一项：

- 即将失去的东西
- 明确羞辱或不公
- 关系破裂
- 紧急危险
- 身份错位
- 不可能任务
- 被隐藏的真相
- 高价值资源即将易主
- 主角的异常能力或特殊限制

首集避免：

- 长旁白讲设定
- 多角色逐一自我介绍
- 不带冲突的日常生活
- 先讲世界观再进入故事
- 用“很多年前”开始但迟迟不回到当下
- 用梦境制造假危机

## 5.3 六种开场结构

### A. 当场失去

主角正失去最重要的资源、关系、身份或安全。

```text
例：婚礼现场，主角被公开指控骗婚；但她发现新郎手中的证据照片被篡改。
```

适合：复仇、爱情、身份、都市。

### B. 倒计时

在极短期限内，主角必须完成任务。

```text
例：凌晨前找不到失踪的工程记录，主角将因重大事故被定罪。
```

适合：悬疑、职场、科幻、犯罪。

### C. 权力反转

原本弱势的人突然获得信息、资源或身份，但代价同时出现。

```text
例：被裁员的设计师收到一份遗嘱，继承公司 51% 股份；签字条件是必须嫁给最大竞争对手。
```

适合：逆袭、豪门、爱情、轻喜。

### D. 禁忌发现

主角发现一个不能知道的秘密。

```text
例：女主在监控录像中看见三天后的自己，正在处理一具尸体。
```

适合：悬疑、奇幻、科幻。

### E. 强关系冲突

主角与最重要的人发生不可回避的冲突。

```text
例：父亲在病床前承认，主角并非亲生，却要求她替真正的继承人顶罪。
```

适合：家庭、情感、复仇。

### F. 错位承诺

观众以为进入一种故事，却迅速发现规则不同。

```text
例：女主以为自己受邀参加精英面试，进门却被告知她是唯一可能活着离开的证人。
```

适合：悬疑、黑色喜剧、科幻。

## 5.4 首集验收

在完成第一集后检查：

- [ ] 前 15 秒内是否出现失衡、欲望、威胁或秘密？
- [ ] 观众能否说出主角当前最急迫的问题？
- [ ] 是否避免连续解释背景？
- [ ] 首集是否至少发生一次状态反转？
- [ ] 结尾是否留下由本集事件自然造成的未结后果？
- [ ] 主角是否至少做出一次主动选择？
- [ ] 是否能用一句话说出“下一集必须看什么”？

# 6. 分集结构

## 6.1 单集微结构

每集以 45 秒至 3 分钟为例，可使用以下节拍：

| 节拍 | 功能 | 观众问题 |
|---|---|---|
| 继承 | 接住上一集后果 | 刚才发生的事会怎样？ |
| 目标 | 明确人物当前要做什么 | 他/她想要什么？ |
| 阻碍 | 对抗力量出现或升级 | 为什么不能轻易做到？ |
| 策略 | 主角采取行动 | 他/她准备怎么办？ |
| 反转 | 信息、权力、关系或计划变化 | 原来不是这样？ |
| 余震 | 展示反转带来的代价 | 现在麻烦变成什么？ |
| 钩子 | 留下未完成且迫切的问题 | 下一集会怎样？ |

注意：并非每集都要平均分配时长。短剧应在进入时尽量“晚进”，在理解结果后尽量“早出”。

## 6.2 每集必须改变什么

一集结束时，至少改变下列一项：

- 目标变得更难或更明确
- 主角获得或失去资源
- 两人关系改变
- 真相范围扩大或被推翻
- 权力地位转换
- 时间压力增加
- 主角越过或守住一道底线
- 新对手加入或旧对手升级
- 观众重新理解前面的事件

如果没有任何变化，该集大概率是无效推进。

## 6.3 分集功能标记

建立 `episode-directory.md` 时，为每集标记主要功能：

| 标记 | 含义 |
|---|---|
| `H` | 高能事件或重大转折 |
| `R` | 关系推进或决裂 |
| `M` | 谜团/信息揭示 |
| `P` | 追更/付费关键点 |
| `S` | 情绪释放或爽点兑现 |
| `B` | 呼吸与人物深化，但仍须带状态变化 |

一集可有多个标记，但不能所有集都标 `H/P/S`。连续高音量会导致阈值上升和疲劳，必须通过人物关系、计划执行和信息变化形成节奏对比。

# 7. 全剧节奏

## 7.1 三段推进

不论总集数，均可按功能划分为三段：

### 第一段：失衡与承诺

观众理解：

- 主角的旧处境
- 核心不公、危机或欲望
- 主角为何不能退出
- 主线的基本规则
- 早期对手和第一次失败

目标：尽快建立“我要看到主角翻盘/揭秘/赢得关系”的期待。

### 第二段：升级与误判

观众经历：

- 主角策略升级
- 对手适应和反击
- 资源、身份或关系多次洗牌
- 中点出现重大胜利假象、失败假象或真相翻转
- 主角发现自己追错了目标或误解了代价

目标：不能只是重复前段的羞辱与反击。必须改变冲突层级。

### 第三段：代价与终局

观众看到：

- 最深秘密或最终对手浮现
- 主角失去旧策略
- 关系和目标发生终极冲突
- 主角以改变后的选择完成或放弃目标
- 主要伏笔回收，结局展示代价

目标：高潮应由人物选择引爆，而不是靠一个凭空出现的救兵、遗嘱、证据或车祸。

## 7.2 中点检查

全剧中段必须至少发生一种重大结构变化：

- 敌我身份互换
- 主角目标被证明是错误目标
- 最亲近的人变成主要阻碍
- 主角得到关键资源，却付出更高代价
- 真正反派浮现
- 核心秘密被部分揭露
- 主角从防御转为主动进攻

如果中点后仍然是“反派羞辱主角 -> 主角小反击 -> 反派再羞辱”，说明故事没有升级。

## 7.3 节奏波形

规划全剧时，用文字或表格标注：

```md
| 集数段 | 主冲突 | 情绪趋势 | 核心事件 | 关键钩子 | 风险 |
|---|---|---|---|---|---|
| 1-5 | 失衡建立 | 快速上升 | 主角被逼入局 | 身份/危机 | 解释过多 |
| 6-15 | 初次反击 | 上升-回落-再上升 | 第一次胜利后更大代价 | 反派升级 | 重复打脸 |
| 16-30 | 中段翻转 | 明显跃升 | 真相或阵营反转 | 核心秘密 | 规则突变 |
| 31-45 | 失控与危机 | 压低后陡升 | 主角失去关键资源 | 不可逆选择 | 人物失智 |
| 46-60 | 终局兑现 | 高潮-余波 | 最终选择与回收 | 终局后果 | 仓促收尾 |
```

具体集数应依项目规模调整，不可生搬。

# 9. 爽点与情绪兑现

## 9.1 爽点不是羞辱合集

爽点应是“建立期待后，以超出预期但符合因果的方式兑现”。

基本结构：

```text
压迫或期待
→ 主角积累资源/信息/能力
→ 对手做出错误判断
→ 主角主动行动
→ 权力翻转
→ 新代价或更高层冲突
```

只让反派不断羞辱主角，或让主角每次靠隐藏身份碾压，都会迅速失效。

## 9.2 五类常用爽点

| 类型 | 核心体验 | 失效方式 | 提升方法 |
|---|---|---|---|
| 身份兑现 | 被低估者展示真实能力/身份 | 凭空身份、重复打脸 | 预埋能力与代价 |
| 能力兑现 | 主角用专业能力解决难题 | 万能主角、无阻力 | 设置更聪明的对手 |
| 关系兑现 | 爱、信任、背叛得到回应 | 误会拖延、人物失智 | 让选择有情感代价 |
| 正义兑现 | 加害者承担后果 | 纯羞辱、价值观单薄 | 让程序、证据和选择成立 |
| 认知兑现 | 真相令前事重新成立 | 为反转而反转 | 回收伏笔、保留线索 |

## 9.3 兑现频率

每 1–3 集应有局部情绪兑现，但规模必须递增或变化：

```text
小兑现：赢得一次对话、获得线索、暂时脱困
中兑现：扳倒小反派、夺回资源、关系站队
大兑现：身份翻转、真相公开、主要阵营改变
终局兑现：主角作出改变后的选择，解决核心问题
```

不要将所有高潮提前消耗。早期兑现的是局部战役，后期兑现的是核心问题。

# 10. 反派与对抗系统

## 10.1 对手必须主动

反派不是“来找茬的人”，而是拥有目标、资源、策略和恐惧的对抗力量。

每个主要对手写清：

```md
- 他想要什么：
- 他为何必须得到：
- 他掌握什么资源：
- 他误判主角什么：
- 他会如何适应主角的反击：
- 他最害怕失去什么：
- 他如何体现或反驳主题：
```

## 10.2 分层对抗

可使用四层对抗，但不要为了“升级”而不断空降新反派：

| 层级 | 功能 | 常见错误 |
|---|---|---|
| 近端阻碍 | 让主角立即行动 | 只负责羞辱 |
| 中段对手 | 迫使策略升级 | 与早期反派功能重复 |
| 核心对手 | 代表主线冲突 | 最后几集才突然出现 |
| 结构性阻碍 | 制度、秘密、时间、规则、创伤 | 被拟人反派替代后失去主题 |

最好的升级不是“更有钱、更能打”，而是对手更了解主角、更能攻击其错误信念和真正软肋。

# 11. 人物与关系线

## 11.1 主角主动性

每 2–4 集检查一次：

- 主角是否在做选择，还是只在挨打和被救？
- 主角是否在执行计划？
- 失败是否迫使主角改变策略？
- 主角是否为了目标承担代价？
- 主角是否逐渐改变其错误信念？

如果主角只是等待身份曝光、贵人相助、遗产到账或反派自爆，则主角不具备持续追看的行动引擎。

## 11.2 感情线

感情线不应只是“误会 -> 和好 -> 新误会”。

每个关系阶段必须改变至少一项：

- 信息透明度
- 信任程度
- 权力结构
- 共同目标
- 风险承担
- 道德边界
- 公开或隐秘状态

关系推进模板：

```text
互相需要
→ 暂时合作
→ 发现不一致目标
→ 关键背叛或牺牲
→ 重新选择对方或彻底决裂
```

## 11.3 秘密分配

建立信息表：

| 秘密 | 真相 | 谁知道 | 观众何时知道 | 何时释放 | 释放后果 |
|---|---|---|---|---|---|

禁止出现人物为了拖剧情而不说一句本应立刻说清的话。若人物隐瞒，必须有具体利益、恐惧、约束或误判。

# 13. 单集写作规范

## 13.1 每集信息卡

写作前先输出：

```md
# 第 N 集信息卡

- 集名：
- 承接的上一集后果：
- 本集 POV：
- 本集局部目标：
- 对抗方目标：
- 本集主要冲突：
- 本集反转：
- 本集情绪兑现：
- 本集结尾钩子：
- 推进的主线：
- 角色状态变化：
- 连续性注意事项：
- 资产/制作注意事项：
```

## 13.2 场景数量

通常每集 2–5 场即可，依单集时长、表演密度和生成成本调整。

场景不是越多越好。若同一地点内的目标和冲突连续，可视为一场；若信息、权力或时间状态发生明显跳变，再拆场。

## 13.3 台词规则

短剧台词应：

- 直接，但不等于解释
- 有目的，但不等于喊口号
- 有区分度，但不靠刻板标签
- 能改变关系或行动
- 尽量短句化，留出反应、动作和剪辑空间

避免：

- 连续三句解释已知事实
- 所有人都用同样的金句
- 角色在紧急状态长篇演讲
- 用“你听我解释”无限延长误会
- 让反派主动完整解释自己的计划

## 13.4 视觉与竖屏空间

写作时考虑竖屏表达：

- 人脸、手部、手机屏幕、门缝、物件、走廊和前后景可承载信息。
- 关键关系冲突优先设计为近景可读的表演，而不是依赖远景群戏。
- 高价值视觉信息应放在画面中部安全区域，避免字幕遮挡。
- 不要将重要证据只写成屏幕上的小字；应通过角色反应、局部特写或口头确认让观众理解。
- 同一场中不要频繁改变服装、天气、伤痕、场景时间，防止 AI 视频连续性漂移。

# 14. AI 制作适配

## 14.1 资产预算优先

在写第 1 集前，建立资产上限：

```md
- 固定主角数量：
- 常驻配角数量：
- 常驻场景数量：
- 核心可复用道具：
- 最大群众规模：
- 最大复杂动作等级：
- 最大特效等级：
- 每集新增资产上限：
```

AI 视频项目中，新的角色、服装、地点、怪物、车、复杂动作和大规模人群都会增加一致性和制作成本。

## 14.2 可复用场景

优先设计 3–8 个能承载多种冲突的核心场景：

- 家 / 公寓
- 公司或工作室
- 医院 / 警局 / 法院的走廊或接待区
- 餐厅 / 酒吧 / 咖啡馆
- 停车场 / 楼道 / 天台
- 控制室 / 办公室
- 城市夜景中的固定地标

场景复用不代表重复。每次回到同一地点，应改变人物目标、权力关系、光线、道具状态或信息意义。

## 14.3 高成本剧情的替代

| 高成本设计 | 保留的叙事功能 | 低成本替代 |
|---|---|---|
| 大规模追车 | 主角逃离、时间紧迫 | 车内近景、后视镜、警报声、路障反应 |
| 群众冲突 | 公开羞辱或社会压力 | 直播界面、电话外放、少数关键目击者 |
| 大型爆炸 | 失控和不可逆损失 | 闪光、断电、警报、人物反应、事后废墟 |
| 复杂打斗 | 权力争夺 | 短促关键动作、道具、门锁、环境限制 |
| 多地跨城 | 阶层/距离障碍 | 手机、新闻、车站、同一可复用转场空间 |

降级时必须保留人物选择与后果，不能仅仅把视觉奇观删掉。

# 15. 国内与出海适配

## 15.1 基本原则

不要把中文台词直译成英文，也不要把文化符号机械替换。

应转换的是：

- 人物的社会约束
- 权力和资源的表达方式
- 观众熟悉的关系场景
- 情感表达的节奏
- 法律、职业、学校、家庭与阶层机制

## 15.2 出海模式检查

若面向国际平台，确认：

```md
- 目标语言是否是最终表演语言？
- 人名、地点、职业和制度是否统一？
- 冲突是否依赖目标市场不易理解的习俗？
- 人物是否具有独立行动逻辑，而非仅由家庭伦理驱动？
- 台词是否自然、简洁、可表演？
- 是否避免将某种文化简化为奇观或刻板印象？
- 是否存在需要当地法律或文化顾问核查的内容？
```

## 15.3 格式

具体的中文文学剧本、英文 Screenplay、Fountain 或 Final Draft 兼容格式，以：

```text
references/screenplay-format-cn-en.md
```

为准。

本文件只规定短剧的故事与生产逻辑，不规定全部排版细节。

# 19. 最终放行门禁

短剧进入制作或导出前，逐项确认：

- [ ] 前三集内已经明确主线失衡、主角目标和主要代价
- [ ] 主角不是被动等待救援或身份曝光
- [ ] 每集至少存在一个明确状态变化
- [ ] 钩子来自人物选择和因果，而非随机中断
- [ ] 反派/对手会学习、反击和升级
- [ ] 同类爽点没有机械重复
- [ ] 每个关键付费点都有前文铺垫和后续兑现
- [ ] 关系线不是无理由误会循环
- [ ] 没有为了凑集数而让人物失智
- [ ] 世界规则、时间线、知情范围、伤病、道具和资产连续
- [ ] 新角色、新场景和复杂动作在资产预算内
- [ ] 已执行短剧专用对抗式审查
- [ ] P0 问题已修复，或被明确标记为接受的创作风险
