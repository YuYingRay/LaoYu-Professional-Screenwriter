# 12. 发布门禁

最终发布、客户交付、公开 Pitch、平台上传、广告投放或商业分发前，必须确认：

- [ ] 所有实际使用的第三方材料均有 `TP ID`
- [ ] 每项材料均记录具体使用位置、方式、地域、平台、期限与商业用途
- [ ] 每项材料均已完成权利层审查，或有明确法务限制说明
- [ ] 所有 `LICENSED` 项的授权证据、授权范围、到期日和署名义务可定位
- [ ] 所有开放许可项已核验版本、兼容性、署名、修改说明、许可文本与分发义务
- [ ] 所有公版项已核验具体版本、适用地域与独立权利层
- [ ] 所有真实人物、声音、肖像、品牌、商标、地点与敏感数据已处理
- [ ] 所有音乐、录音、声音、字体、地图、UI、图片、视频、代码、模型与数据已审查
- [ ] 所有 AI 输入、平台条款、输出审阅与相似性风险已记录
- [ ] 所有必要署名、许可证、NOTICE、片尾、README、About 和下载包内容已加入
- [ ] 未授权、过期、争议或禁止材料已被移除、替换或阻断发布
- [ ] 任何权利变化已通过 `upstream-notices.md` 同步至剧本、镜头、资产、字幕、声音与生产文件
- [ ] 法务、顾问、客户、平台或制作方要求的审批已记录
- [ ] 无未关闭 P0；任何 P1 例外均有书面接受、负责人、补偿措施与到期日
