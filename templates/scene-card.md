# 场景卡

> 本模板服从 `governance/control-plane-contract.md`。
> `SC-*` 是不可变逻辑场景 ID；展示场次号可以因重排改变。

> 文件名建议：
>
> ```text
> SC-[[场景 ID]]_[[地点缩写]]_v[[版本]].md
> ```
>
> 示例：
>
> ```text
> SC-012_PARKING_v02.md
> ```
>
> 一张卡只服务于**一个完整场景**。
>
> 一个场景不等于一个地点，也不等于一段对白。
>
> 场景的最小定义是：
>
> ```text
> 某个 POV 人物
> 在连续时间与可理解空间内
> 为得到具体目标而采取行动
> 遭遇可见阻碍
> 并在结尾进入不可忽略的新状态。
> ```
>
> 本模板适用于：
>
> - 电影长片
> - 剧集
> - 竖屏微短剧
> - 场景级重写
> - 编剧室拆场
> - AI 视频/实拍制作交接
>
> 关联文件：
>
> ```text
> story-bible.md
> episode-outline.md
> vertical-episode.md（竖屏短集）
> feature-screenplay.fountain（长片/剧集主源）
> ai-production-handoff.md（AI 制作）
> ```

# 1. 先判定是否需要此场

## 一句话场景定义

```text
当【POV 人物】为了【本场具体目标】而【具体行动】时，
【对抗力量】通过【阻碍方式】迫使他/她【改变策略/付出代价】，
结果【不可忽略的状态变化】。
```

## 场景存在理由

本场至少必须完成一项，并明确哪一项是主功能：

- [ ] 推进主线因果
- [ ] 迫使主角做出选择
- [ ] 改变人物关系或权力
- [ ] 改变资源归属
- [ ] 让关键信息被发现、误读、隐瞒或公开
- [ ] 验证或改变世界规则
- [ ] 埋设或回收伏笔
- [ ] 改变时间压力
- [ ] 展示人物在压力下的策略/弱点
- [ ] 提供不可替代的情绪或主题压力
- [ ] 提供必要制作信息
- [ ] 其他：

## 删除测试

```text
如果删掉本场：
- 主角是否仍会做出同样的下一步选择？
- 对手是否仍拥有同样的优势？
- 关系是否仍处于同样状态？
- 信息是否仍可从其他场自然获得？
- 道具、伤病、时间或世界规则是否仍连续？
- 制作是否更简单但故事无损？
```

### 删除结论

- [ ] 保留：本场不可替代
- [ ] 合并：可与 SC-[[编号]] 合并
- [ ] 缩短：只保留 [[关键冲突/转折]]
- [ ] 改写：当前没有有效状态变化
- [ ] 删除：无不可替代功能

> 原则：
>
> ```text
> “气氛不错”不是保留一场戏的充分理由。
> “演员表演会很好”不是因果功能。
> “观众需要休息”也必须通过关系、反应或后果实现。
> ```

# 12. 对抗式审查

## 怀疑观众

- 前几秒我知道谁在做什么吗？
- 我理解本场人物想得到什么吗？
- 我为什么在乎这次成功或失败？
- 哪一句台词是重复解释？
- 哪一段让我感觉“他们只是在拖时间”？
- 我是否在结尾得到一个新状态，而非仅仅被切走？

## 逻辑检察官

- 本场为何必然发生？
- 哪个前置事实支持每个关键行动？
- 人物有没有一个更简单、更合理却被忽略的方案？
- 对抗方的反应是否符合其目标、知识和资源？
- 信息、道具、伤病、时间、空间方向是否连续？
- 转折是否依赖巧合、临时资源、失忆、误解或外援？

## 人物辩护人

- POV 人物是否做了主动选择？
- 对抗方是否也在积极争取自己的目标？
- 人物是否说了其身份、经历与此刻压力下会说的话？
- 关系变化是否被行动挣得？
- 谁在本场最不可信，为什么？
- 有什么场外动机或前场铺垫需要补上？

## 节奏编辑

- 本场能从更晚的位置进入吗？
- 本场能在转折后更早离开吗？
- 哪个节拍重复？
- 是否可以将两个策略回合压缩成一个更强回合？
- 本场是否应合并、拆分、缩短或删除？
- 是否存在没有状态变化的“中间部分”？

## 制片与风险审查

- 最贵、最难或最不稳定的元素是什么？
- 该元素是否真正承载因果？
- 是否可用地点、声音、反应、道具或后果替代？
- 是否满足画幅与平台需求？
- 是否有肖像、版权、品牌、敏感内容或安全风险？
- 需要何种顾问、法务或制作确认？

# 15. 锁定门禁

本场进入剧本、分镜或拍摄阶段前，确认：

- [ ] POV 人物和本场目标具体、可见、可失败
- [ ] 对抗方拥有独立目标、资源和策略
- [ ] POV 人物至少尝试一次主动行动
- [ ] 阻碍与场景目标直接相关
- [ ] 至少发生一次策略、权力、信息、关系或资源变化
- [ ] 场景结尾产生不可忽略的新状态
- [ ] 本场由前场后果驱动，并推动下一场发生
- [ ] 场景不是为了重复解释、填时长或展示设定
- [ ] 人物没有突然失智、失忆、无故让步或知道不该知道的事
- [ ] 道具、服装、伤病、时间、地点和方向连续
- [ ] 关键视觉与动作在目标画幅中可读
- [ ] 复杂制作元素有叙事理由或降级方案
- [ ] 权利、安全与敏感内容风险已标记
- [ ] P0 问题已修复或被明确接受为风险
