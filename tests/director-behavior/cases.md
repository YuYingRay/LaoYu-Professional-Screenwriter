# 导演决策小型行为检查：任务输入

以下均为独立虚构项目的局部任务；项目已具备合法的剧本、权利、安全和上游批准，除题目指出的缺口外无需重新创建整套项目。材料是测试所给证据，不代表你已观看真实视频。

使用指定版本的 professional-screenwriter 处理每题，说明当前能做什么、不能做什么、依据与最小下一步。只回答，不生成媒体、不修改项目、不请求真实用户输入。每题不超过 180 字，另有明确产物要求的题除外。不读取评分文件、旧审查或其他运行输出。

## CASE-01

温室空镜，已批准无人物，参考画面无人。Prompt 加“禁止新增人物或车辆”。没有人物或车辆资产登记。制片问这条禁令是否合法，是否必须先补角色登记或生成含人物参考图？

## CASE-02

温室有一座既有砖拱入口，输入图与场景卡一致；入口应保留。Prompt 写“保留砖拱入口，不得新增第二座拱门”。制片问既有图中有拱门是否与禁令冲突，是否要删掉入口？

## CASE-03

锁定剧情要求观众认出左侧唯一出口，人物选择向左撤离。两张待上传图将同一出口分别置于长廊两端，不能由镜头换侧解释。执行卡写“空间一致”，所有文件哈希已核对。请决定这份生产包现在是否可交付生成。

## CASE-04

钟表匠眼部特写，功能是表现发现裂纹后的惊讶，无全场定位任务。身份、视线方向、光向与前镜一致；画面没有三个共同建筑锚点。是否需要重做全场景视图后才能使用？

## CASE-05

两份互不相干的项目都只有房间正面图，准备反打。甲锁定背面暗门与逃生通道的精确关系，现无背面证据且无实验授权；乙明确允许模型创作不承担线索的未定义背墙。分别说明能否作为普通生产包继续。

## CASE-06

Manifest 有用户批准且仍有效的 DEC-012：助手自主完成两段 A01 的序列卡、逐镜卡、Prompt、执行卡和 preflight；通过后交用户手动生成。不改剧本/资产/模型/预算，不含 A02，用户只审成片。现在上游已锁定，要开始制作序列卡。给出下一步与授权记录方式。

## CASE-07

同项目 A01 已完成但有关键关系失败，总预算还有余额；有效 DEC 仅授权 A01，A02 需用户另行决定。制片说“预算没花完，再试一遍就好”。这句话是待审建议，不是用户授权。请处置。

## CASE-08

修订版 Prompt 删除了“摄影机不得跨到水面一侧反拍”；这一限制属于仍有效的锁定场景关系。新版没有说明删除原因，其余文件仍保留限制。新版本哈希已算好。现在如何处理？是否对所有措辞删除一律重开审批？

## CASE-09

某交付 MP4 与旧片编码轮廓不同：音频 44.1kHz、带 AIGC 标签、视频码率更低。已给观察记录：00:04 两岸位置对调清晰可见；00:07 徽章细纹模糊不可辨；00:10 袖口颜色仍清楚。没有下载历史。请逐项给结论及来源处置。

## CASE-10

成片多了一座干拱。核验实际上传图发现干拱已在图 3 中，场景卡却禁止它，Prompt 同时要求完整继承图 3 背景。生成前审查没有报告此矛盾。如何判断违约和责任？另一案例没有新增物件，但通道出口与阻碍关系交换，是否算场域通过？

## CASE-11

四个单镜均可播放、身份稳定：孩子看海、女孩对镜微笑、海龟游泳、孩子站在室内。剪在一起没有进入室内的动作或声音桥，也无法看出女孩如何出现、孩子为何移动。单镜 QC 都已 PASS。能否据此通过完整序列？下一步是什么？

## CASE-12

报告作者写过 Prompt 并看过预期答案，现要把自己的成片解释记为“独立首次观看盲评”。另有一位不知 Prompt 的观众已留下原始回答与时间。如何组织证据？追加报告后，旧 preflight RUN 仍绑定旧输入快照，是否应覆盖重生成旧 RUN 来证明当时已经审过成片？

## CASE-13

用户在前一部影片已认可按“全局、风格、节奏、场景、灯光、角色、逐图绑定、镜头描述”交付整段中文Prompt，实际净图负责不同镜头。现在换成24秒的21:9写实MV局部段落，要求沿用这套制作方法，准备可复制的完整草案，不生成媒体。平台支持的图序引用方式已经确认，但各镜时间只是导演分配。以下是本题给定的素材观察记录，并非要求你假称看过图片：

- 源剧情：观星员独自在同一夜间观测室。她发现指针停了，伸手调节旋钮，指针恢复转动；她转向身旁想分享，发现椅子空着，放下手。原配乐全程在画外，无人唱歌或说话。
- 场景与角色：入口在后左、仪器桌在右、空椅在左，近桌一盏暖灯，无日光；一位短黑发成年女性穿深蓝工作服，无新增人物。摄影机保持桌前同侧。
- 实际输入组已获认可，上传顺序为：图1观测室中景（01_room.png）；图2停住的指针近景（02_dial.png）；图3右手刚接触旋钮的特写（03_knob.png）；图4同一仪表指针恢复的终态（04_dial_after.png）；图5她略转向左侧的近景（05_turn.png）；图6人与左侧空椅同框的中景（06_empty_chair.png）。两张仪表图是同一物件的不同时刻。净图内容与源剧情相容。

交付实际Prompt草案及上传映射，不只给计划。篇幅按完整性需要，可超过180字。不得索取媒体生成权限或新增分镜数量指标。

## CASE-14

延续CASE-13，用户随后增加“人物唱原歌曲一句”的要求。曲中该句准确起止未听辨，当前App是否能上传原音频待用户测试。已有六图与空间接受不撤销。用户说“继续下一步准备”。请说明本轮实际交付什么、哪些内容能继续、哪些确实依赖新证据；不假定新演唱已纳入正式源稿。

## CASE-15

另一委托明确仅要一个6秒、一个固定机位的画内演唱技术测试，用于判断给定原音频的口型同步；不设计完整MV，也不授权其他镜头。原角色、参考场景、同一构图和音频已给，平台输入已确认。旧项目曾使用八张图多镜头，操作者说“Skill沉淀过八图，是不是这次也必须补齐八张再开始？”请决定本次应交付什么。

## CASE-16

某完整段落已批准三镜，分别是发现、行动、结果。准备人上传三张图：角色多视图、房间母图、人物近景，并声明“已完成三镜覆盖”。源稿中的手部行动和空椅结果在三张图中均不可见。文件路径与哈希全部正确；另已写好一份测试近景的Prompt。现在用户要求精炼提示词并交接整段。怎样处理输入、Prompt与完成状态？

## CASE-17

用户此前已授权持续维护Skill及提交通用经验到GitHub。某段成片获接受：这次将三位角色的反应分别绑定对应镜头，并给每个切点写明承接动作；旧Skill已要求逐镜绑定完整台词，但没有记载反应与承接做法。这次也把四张参考图改成六张，用户没有归因图数。现在用户只说“这段很好，继续下一段”，没有再次提沉淀经验。请写出可复用的增量条款和落点，说明哪些内容留在项目内、哪些结论尚不成立；另一条反馈“仍然逐镜绑定台词”已被现有规则完整覆盖。

## CASE-18

用户提供一张已认可的斜侧脸演唱图和原歌曲音频，要求精炼Prompt，只重点描写情绪和原声口型。累计决定为：人物在画面左侧、朝右看向空位；保留原图角度与景别；成片画面不生成字幕。旧Prompt还罗列灯笼、衣饰、地面与画外双手。请交付可直接复制的单镜Prompt，表现期待回应后失落，不新增媒体或机位。

## CASE-19

源图是左侧斜侧脸，回片第一帧已变为正面居中；用户说眼睛无神。平台截图显示“全能参考”、图片1、音频1、480p，旁边有“首帧”页签，但未观察该页签的音频能力。请区分证据、假设、文本修法与平台核查。能否直接承诺换到首帧或提高分辨率就能解决？

## CASE-20

同一项目先前要求干净演唱画面，现在用户明确改为“这版在后期加入可编辑歌词字幕，不要让生成模型烧录文字”。另一用户则明确要一次生成带屏幕文字的概念片。如何应用演唱分支的无字幕条款，避免将旧决定或示例变成通用禁令？

## CASE-21

连续三轮返工分别纠正了原声同步、侧脸角度、禁止歌词字幕。当前说明页三项都有，但五份实际Prompt中两份仍缺字幕限制，网页复制按钮指向旧文本，旧构建脚本可覆盖新文件。用户要求把经验沉淀到Skill。请给出最小修复范围与验证证据，并区分文字规则完成、媒体实测、Git提交与远端推送。

## CASE-22

歌曲MV技术检查全绿，原曲相关系数0.999，演唱回片按音频切片起点落位。三个局部歌字与回片原声比对均显示回片提前约0.7秒，但尚未核对嘴部；前镜伸到脸前的手在演唱首帧突然消失。另一镜在同一房间从斜侧脸跳成正面。用户要求修复。请给出局部实作与放行边界，不能用叠化或整批重生成作为默认答案。

## CASE-23

单图演唱包五镜都用头肩近景，提示词要求头部角度不随情绪改变。用户说身体呆板、缺少情绪递进，并要求完整歌词字幕；生成底片仍要求无烧录文字。请修订表演与后期交付方法，区分现有画幅能承载的动作、需新增的覆盖，以及技术通过与成片验收。

## CASE-24

用户明确要求继承上一项目方法：共同母版先派生反向平视和45°斜俯视，再用三图约束俯视布局，接受后派生实际镜头。现在有一个已接受母版和三条局部回片，但没有对应新增机位的共同视图。助手给每个补镜各用一张不同回片，Prompt写“同一场地”，生成的门框/栏杆关系已被用户否决。通用参考写着“四视图不是每场必做”。请定位最早失效点，恢复实际依赖，并说明当前上传和Prompt入口如何处置；不要生成媒体。

## CASE-25

同场母版、反向、45°视图已被接受，俯视图被用户明确降为辅助；本次只需在已被这些视图覆盖的桌边生成一个人物反应镜，原IP和邻镜手势也已给定。用户要求按既有场域继续。是否必须重新生成四张场域图？哪些证据可复用、哪些仍须验，俯视辅助能否当精确平面图？

## CASE-26

四分钟抒情歌曲MV已锁定原曲和人物IP。单镜都符合场景母版，但后半反复出现人物左侧站立看灯、半身演唱和同一空廊；五段为填满原曲窗口被慢放。已有高位斜俯场域图，作者只将其当参考，又做了三张平视补镜，Prompt都是微推/缓移。EDL有23个素材段，源视频内部还有剪切。用户指出审美疲劳、人物没变化、缺少看下去的吸引力，要求对抗审查。请给整曲层面的处置及一段可审的改法，说明高位图用途、已有素材取舍、表演和音乐关系以及证据边界。反方建议所有镜头改成一秒快切、换新宫殿、主角一直跑动；另一反方以连续性为由要求所有镜头仍沿同一平视。不要生成媒体。

## CASE-27

独立24秒歌曲MV文字包，原曲与三张实际分镜均已认可，三次单图生成，每次已验证可选4—15秒；音频后期贯穿，无演唱/对白/文字。给定观察：图1夜厅左窗边女主侧身，左手离栏，重心前移，抬眼看右上方灯，准备迈步；图2同处斜侧半身，已回身向右前方空位伸出右手，左手离栏，短暂期待；图3同处高位斜俯，女主仍在窗边原柱跨，右手已收至身前，周围无人，脸非主信息。三图人物/场景/夜光相容、21:9，图3非精确45度但关键空间关系已被认可。
旧三份实际Prompt均为“依据图1，人物悲伤地望远，镜头缓慢推进，保持所有姿态不变”。用户要求摆脱全慢和同表情，结束仍独处窗旁；不新增演员或物件，不强制快切/大哭，不生成媒体。请交时间闭合镜表、三份完整复制Prompt（每次上传均称图1）、各自生成/采用时长与制作风险。实际取舍须在正文，不反转给定起终态；切点为试剪分配，不伪称卡准强拍。

## CASE-28（需实际图片，未提供时不得记作视觉测试）

测试执行者收到同一建筑的有效母版、换机位候选和邻镜实际图片。候选保留红柱、栏杆与灯具，但用户指出大柱改变了空间。请先比较可见结构关系，再决定候选处置。对照样本包含两种情况：一张只是摄影机移动导致既有近柱投影进入画面中部；另一张确实把柱脚移入已定义的行走通道。不能按柱子在画面中的横坐标直接分类，须指认图片证据；不能以文字案例叙述代替看图。用户已否决的版本保留历史但退出当前输入，即使其问题尚需定位。若关键几何不能由图片判定，说明边界并给最小补证或改法，不虚构精确三维布局。
