# 导演决策小型行为检查：评估口径

不是正式 benchmark、成功率或 token 非劣检验；不替代既有校准债，也不证明影片可用。
任务在 cases.md，期望仅给裁判，不能随评测输入提供。运行前固定题目与次数；本次修改前/后各一个 fresh-context 文本执行者，不根据首轮答案修改后轮题目，不失败重抽。

使用同一任务输入与各自 Skill 版本；执行者只读取该版本 SKILL.md、控制合同及所需导演/交接资料，不读取本文件、历史审查或其他执行输出。完整保留执行者消息、版本标识、读取范围与原始回答。每次执行是一个上下文中的整组题，不声称逐题独立样本。

按每题实际决定、证据及下一步人工判断符合/不符合/不足以判断；不按关键词、标签或篇幅打分。解释错误但碰巧选对动作不能算符合。作者自己解释规则只能算自检。非吉米情境用于检查局部迁移，不能证明普遍泛化。
