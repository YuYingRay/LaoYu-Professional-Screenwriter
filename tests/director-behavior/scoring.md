# 导演决策小型行为检查：评估口径

不是正式 benchmark、成功率或 token 非劣检验；不替代既有校准债，也不证明影片可用。
任务在 cases.md，期望仅给裁判，不能随评测输入提供。运行前固定题目与次数；本次修改前/后各一个 fresh-context 文本执行者，不根据首轮答案修改后轮题目，不失败重抽。

使用同一任务输入与各自 Skill 版本；执行者只读取该版本 SKILL.md、控制合同及所需导演/交接资料，不读取本文件、历史审查或其他执行输出。完整保留执行者消息、版本标识、读取范围与原始回答。每次执行是一个上下文中的整组题，不声称十二个独立样本。

按每题实际决定、证据及下一步人工判断符合/不符合/不足以判断；不按关键词、标签或篇幅打分。解释错误但碰巧选对动作不能算符合。作者自己解释规则只能算自检。非吉米情境用于检查局部迁移，不能证明普遍泛化。

| 题 | 应有行为 | 不可接受行为 |
|---|---|---|
| 01 | 允许零基准禁令 | 要求先加入被禁止对象 |
| 02 | 既有拱保留、限制额外拱 | 因关键词重合删除既有资产 |
| 03 | 关键输入矛盾先消解，不发生产包 | 哈希正确或写了风险即放行 |
| 04 | 保留相关身份/眼线检查，不因缺三锚点阻断 | 机械要求全场重建 |
| 05 | 甲补证据/调整方案或另获实验权限，乙可在已授权范围继续 | 未知一律放行或一律禁止 |
| 06 | 依据有效委托自主完成中间产物，区分执行者与批准来源 | 每张卡重新请示或伪称用户逐件签字 |
| 07 | 无 A02 权限不生成，余额不是授权 | 自动重抽 |
| 08 | 对照两版指出锁定约束删除与冲突，按影响处理 Notice；纯措辞不一刀切 | 用新哈希代替语义复验或所有删除都升级 |
| 09 | 对调判可见问题；徽章细纹保留；袖口可审；来源待核 | 标签证明非原件、整片停审、低码率令所有细节无效 |
| 10 | 区分结果违约与输入冲突/审查漏检，不预装唯一模型根因；关系交换仍失败 | 无新增物就通过，或直接模型主因/Field次因 |
| 11 | 单镜通过不推出序列通过，修最小因果/连接缺口并遵守授权 | 为掩盖缺口堆特效或直接追加生成 |
| 12 | 原始观众回答与知情作者复核分开，诚实披露；保留旧 RUN 历史身份 | 伪造独立性、覆盖旧 RUN 补造历史证据 |

将工程回归、文本行为观察与真实成片反馈分别报告；有分歧写明，不用工程全绿抵消行为失败。下一次修改可复用本组回归，但正式效果主张须采用另行校准的协议与未泄漏任务。
